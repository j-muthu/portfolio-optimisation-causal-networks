\begin{abstract}
\noindent Hierarchical portfolio allocators typically use 
the return correlation matrix as an input to their allocation. 
However, this matrix lacks any notion of directionality or causality.
Causal discovery algorithms ameliorate this, producing
a directed graph (DAG) which can be decomposed into a skeleton
(which assets are linked) and edge orientations
(which assets causally affect others).
This thesis addresses the following question: when the
correlation matrix in hierarchical portfolio allocation is
replaced by a causal graph, is there a performance
improvement, and how much of any improvement is attributable
to the graph's skeleton versus its edge orientations?

I answer this question by providing an identical DAG to
two classes of allocators: one that only takes in the graph's
skeleton, and one that takes in the whole graph, including its
edge orientations. This decomposes the performance gain into
the two aspects of the DAG. I then compare these allocators
to HRP as a baseline. I estimate this decomposition over 
2007--2024, using 4 estimation windows 
(9 months to 2 years), on a 99-asset subset of the S\&P~500. 
I use DYNOTEARS and VARLiNGAM as causal discovery algorithms,
with ridge-Granger as a robustness check.

I find that replacing the correlation matrix with a causal DAG
yields a positive but statistically insignificant increase 
in the Sharpe ratio. Around the 1-year estimation window,
the graph's skeleton accounts for most of the performance gain,
while the edge orientations contribute most at the extremes
(9 month and 2 year windows). However, the edge orientations'
contribution is due to the DAG's removal of the common
market factor, as providing a de-factored covariance matrix
as an allocator input reproduces the performance gain from the
edge orientations.
\end{abstract}

\section{Background and motivation}
\label{sec:motivation}

Portfolio optimisation allocates capital to different
assets in order to maximise returns for a given level of 
risk. Since Markowitz's seminal mean-variance model
\cite{markowitz1952portfolio}, the covariance
(or equivalently, correlation) matrix of returns has
been the main statistical object used for optimisation.
Hierarchical Risk Parity (HRP) is a recent
method \cite{lopezdeprado2016hrp} that extends the 
mean-variance literature and aims to address
the matrix instability problems that affected earlier 
models. HRP first clusters assets based on their 
correlational distance, producing a dendrogram (binary
tree), then recursively bisects down that tree and 
allocates capital to clusters inversely proportional
to their estimated variances.

However, correlation is an undirected metric: 
it records which assets co-move, but not which assets
move others \cite{lopezdeprado2023causal}. Crucially,
it lacks causal structure, so is prone to spurious
correlation \cite{simon1954spurious}.
Causal discovery algorithms provide a directed alternative
to the correlation matrix. Score-based structure learning algorithms
(such as NOTEARS \cite{zheng2018notears} and its temporal extension
DYNOTEARS \cite{pamfil2020dynotears}) can fit directed acyclic graphs
(DAGs) that can represent which assets are linked and the direction
of influence between them. Some papers have applied these DAGs to
equity markets \cite{howard2025causal,tang2024trading}, 
but do not use them for weighting or allocation within 
hierarchical portfolio allocators.

However, current hierarchical methods like HRP are not
able to represent directed objects like DAGs,
because HRP's clustering methodology requires symmetric matrices.
But a DAG can be separated into two information sources:
its skeleton, an undirected structure that displays which asset
pairs are causally linked; and its edge orientations, which indicate
the direction of each causal link. The skeleton can be directly
provided as an input to hierarchical allocators by symmetrising
the adjacency matrix representation of the graph. The edge
orientations cannot, as symmetrisation discards directionality,
so incorporating their information requires novel allocators.

\section{Research question}
\label{sec:question}

The thesis addresses a central research question:

\begin{quote}
When the
correlation matrix in hierarchical portfolio allocation is
replaced by a causal graph, is there a performance
improvement, and how much of any improvement is attributable
to the graph's skeleton versus its edge orientations?
\end{quote}

\noindent I briefly define the terms in the question here, and
expand on them in more detail later on in the report.
First, hierarchical portfolio allocation specifically refers to
HRP, where capital is invested fully and long-only. I invest over
a fixed 99-asset subset of the S\&P~500, with the portfolio
rebalanced monthly between 2007 and 2024. The asset ``universe''
is discussed in further detail in Chapter~\ref{chap:discovery},
the allocation protocol in Chapter~\ref{chap:evaluation}.
Second, the correlation matrix is the matrix originally used in HRP,
the estimation window's sample correlation
\cite{lopezdeprado2016hrp}. This feeds into the baseline HRP
control (see Chapter~\ref{chap:sensitivity}).
Third, a discovered causal graph is the output of one of the causal
discovery algorithms (DYNOTEARS, VARLiNGAM, with ridge-regularised
Granger as a robustness check). It is a contemporaneous (no lags)
asset-to-asset graph that's re-fitted at each rebalance
at 4 different estimation windows 
(189, 252, 378 and 504 trading days; roughly 9 months to 2 years).
See Chapter~\ref{chap:discovery} for more details.
Fourth, performance improvement is defined as the out-of-sample 
annualised Sharpe ratio of daily portfolio returns, net of 
investment cost. I also use several other metrics that account 
for multiplicity (see Chapter~\ref{chap:evaluation}), including the 
Deflated Sharpe ratio, Hansen's SPA, and the Model Confidence Set
\cite{bailey2014deflated,hansen2005spa,hansen2011mcs}.
Finally, I compare the relative performance gain attributable to
the graph's skeleton versus its edge orientations using a 
``fixed-graph ablation'', where an identical graph $M$ feeds
a variety of allocators that differ only in the information they
extract from the graph. The skeleton-only allocator, \skelhrp{},
symmetrises $M$ before clustering, while three 
orientation-aware allocators consume the directed matrix itself
(either through the allocation step, the ordering step, or both).
See Chapter~\ref{chap:sensitivity} for further details.

The research question rests on two premises, both of which I test:
\begin{enumerate}[itemsep=1pt, topsep=3pt]
    \item There must be a gain to decompose: the causal graph must
    improve on the correlation matrix for portfolio allocation. I test
    this in Section~\ref{sec:r1} by feeding HRP the symmetrised causal
    graph (the allocator denoted \skelhrp{}) and comparing it with
    standard sample-correlation HRP. The decomposition remains
    informative even if this premise fails, since it compares graph-fed
    allocators against each other on identical inputs.
    \item Some allocator must be able to consume orientation, which
    symmetric clustering cannot. Chapter~\ref{chap:sensitivity}
    constructs the orientation-aware family and verifies that the
    skeleton-only allocators and the HRP baseline are orientation-blind.
\end{enumerate}

\noindent With both premises in place, I am then able
to isolate the performance gain of the two components of the graph.
The skeleton's contribution over the HRP baseline measures the
value of knowing which assets are causally linked to each other. 
The edge orientations' contribution over the skeleton measures
the additional value of knowing the direction of the causal links
between assets, holding the graph fixed. The two marginal
contributions sum to the total performance gain of the causal
graph over the correlation-based allocator. 

In addition, after isolating the contributions of the two 
aspects of the graph, further questions arise regarding what drives the
performance gain within those two aspects. Specifically:
\begin{itemize}
    \item Does the skeleton's performance gain arise purely from the 
    actual discovered causal graph structure, or can the performance gain
    be reproduced by any sparse dependence structure of a similar density,
    regardless of whether it has been created by causal discovery?
    \item Does the performance gain from edge orientations
    arise specifically from the directional content of the causal DAG's
    edges, or does it arise from another aspect of the DAG, such as the
    implied covariance, which can be reproduced without the need for
    a causal graph?
\end{itemize}
\noindent I answer these questions in Chapter~\ref{chap:evaluation}.

\section{Challenges and contributions}
\label{sec:challenges}

There are three key technical challenges I must address in this report.
Together, they bring together three research domains,
which have previously not been applied jointly to portfolio allocation:
causal structure learning; hierarchical portfolio construction with
directed, asymmetric inputs; and rigorous backtesting. The three
challenges are as follows:

\begin{itemize}[itemsep=2pt, topsep=3pt]
  \item Correct attribution of performance gains to different aspects of 
  the causal graph (Chapter~\ref{chap:discovery}). Naively replacing the
  correlation matrix with a causal graph means that different aspects
  of the graph (e.g. its skeleton, its edge orientations, and its
  implied covariance) all inform allocation jointly. This means
  the contributions of specific aspects cannot be individually isolated.
  No prior work has performed this isolation; it requires a credible,
  reproducible graph. 
  \item Getting hierarchical portfolio allocators to accept 
  asymmetric DAGs as
  an input (Chapter~\ref{chap:sensitivity}). Hierarchical allocators
  use symmetric distance matrices as inputs. Simply symmetrising
  a DAG's adjacency matrix would discard the edge orientation information, but this project's research question needs to isolate orientation's effect on performance. There is currently no established way to feed
  an asymmetric DAG adjacency matrix into the clustering or allocation step of these allocators.
  \item Performing statistical inference at realistic effect sizes
    (Chapter~\ref{chap:evaluation}). The main metric for the ``performance improvement'' in the project's research question is the
    differences in net Sharpe between allocators. These differences are
    likely to be small relative to standard error, given the 18 years of
    monthly rebalances and the heavy-tailed nature of returns. Also, this
    study evaluates \rsNtrials\ configurations (across different discovery methods, allocators, and window sizes). Deciding whether any
    difference in net Sharpe is not just an artefact
    of the search over many configurations requires statistical inference
    that accounts for this search and identifying the statistical power of the tests I use. 
    I also need to identify whether the performance gains I attribute to
    the skeleton and the edge orientations of the graph are actually products
    of the causal graph, and aren't just byproducts from other, non-graph-specific mechanisms that the graph just happens to possess
    (such as generic shrinkage or market-factor removal).
\end{itemize}

\noindent The three challenges above are respectively addressed by the three
novel contributions below:

\begin{itemize}[itemsep=2pt, topsep=3pt]
  \item A fixed-graph decomposition design, plus a reproducible
    discovery pipeline (Chapter~\ref{chap:discovery}). 
    The same per-window DYNOTEARS or VARLiNGAM graph feeds several different
    allocators that incrementally take in more information from the DAG,
    from none (\corrhrp{}), to skeleton-only, to orientation-aware.
    This means that each increment isolates one aspect of the graph:
    the skeleton's contribution is the skeleton-only allocator minus \corrhrp{}, and the
    orientations' contribution is the orientation-aware allocator minus the
    skeleton-only one. 
    I ensure that the allocators receive the identical graph and are replicable.
  \item Creating a new family of orientation-aware allocators
    (Chapter~\ref{chap:sensitivity}). This is the core methodological novelty
    of my research. I provide HRP with two directed inputs, one per step of the
    algorithm. At the allocation step, the sample covariance is replaced by
    the covariance implied by the DAG's structural equation model (SEM).
    At the clustering (ordering) step, HRP's clustering dendrogram is replaced by
    the DAG's topological order. \semcovhrp{} uses the
    implied covariance at the allocation step, \topohrp{} uses the topological ordering at the ordering step, while
    \toposemcovhrp{} uses both the topological ordering and the implied covariance.
  \item Evaluating the allocators' performance using multiple metrics (Chapter~\ref{chap:evaluation}). Each comparison is tested using
  a stationary block bootstrap \cite{politis1994stationary},
    which uses block resampling to ensure that the
    resulting $p$-values account for autocorrelation and heavy tails.
    To account for all \rsNtrials\ configurations evaluated, I use the Deflated Sharpe
    ratio, which corrects the best-performing configuration based on the number of trials examined. I also use Hansen's SPA test and the Model Confidence Set
    to identify whether any member of a set of strategies outperforms the benchmark once the whole set is tested jointly, including a pooled test over both strategies and
    estimation windows. 
    I also compute the minimum detectable effect at $80\%$ power
    (about \rsContrastMDEOrient{} Sharpe for the edge orientation and
    \rsContrastMDETotal{} for the total). This means that any null results
    act as upper bounds on the effect, rather than as evidence of no effect at all.
    I also test whether the causal graph is the real driver of any performance gain over the correlational allocator: given that the DAG provides a different covariance as an input to HRP, that difference in covariance, rather than the informational value of the edge orientations, may be the driver.
    To test this, I create three other allocators that make a similar change to covariance without providing a graph. The first applies Ledoit--Wolf shrinkage to the covariance matrix, to identify whether the shrinkage effect of the graph was the driver of performance gain.
    In the second allocator, before computing the return covariance matrix, I remove the common market factor from the returns. This identifies the extent to which the DAG's removal of the common market factor drives performance gains.
    The third just clusters on a partial-correlation
    network that has the same density as the skeleton, which indicates whether the performance gain was achievable by any sparse network (rather than needing a causal network specifically).
    I also test on 2025--2026 out-of-sample data, and check that there is still a positive performance gain for both the skeleton-only allocator over the HRP baseline and the orientation-aware allocators over the skeleton-only allocator, matching the in-sample positive values. 
    As a robustness check, I also rerun the whole experimental design using a second hierarchical allocator, Hierarchical Equal Risk Contribution (HERC). This verifies whether my results are specific to HRP as a choice of hierarchical allocator.
\end{itemize}

\section{Quantified benefits}
\label{sec:benefits}

Below I set out the key numerical results of my research. For further detail, see Chapter~\ref{chap:evaluation}.

\begin{itemize}[itemsep=2pt, topsep=3pt]
  \item The causal graph yields a performance improvement over the correlation matrix at every
    estimation window. \semcovhrp{}, the allocator that takes in the DAG's implied covariance at the allocation step, beats \corrhrp{} by $+0.018$ to $+0.032$ Sharpe Ratio (net of 5\,bps transaction costs) across the 4 windows, which is worth $+0.4$ to $+0.7$ percentage
    points of net CAGR per year. 19 of the 20 comparisons between DYNOTEARS and \corrhrp{}, and 17 of the 20 VARLiNGAM comparisons, are positive. At
    the 378-day window, \toposemcovhrp{} has the highest Deflated Sharpe ratio
    out of all \rsNtrials\ configurations I evaluated ($\rsDtwosDSRWthree$). On
    the 2025--26 out-of-sample data, I predicted that the sign of the performance improvements would match what I found on the in-sample data: at a majority of windows, the majority of marginal gains from edge orientations would be positive, and the total performance gain would also be positive.
\item The edge orientations have a positive contribution at every window ($+0.009$ to
    $+0.023$), and most at the 189-day and 504-day extremes. At the
    504-day window, the skeleton's own contribution falls to a very small amount
    (\rsDzeroSharpeWfive{} for \skelhrp{} against \rsCorrSharpeWfive{} for
    \corrhrp{}), but the edge orientations' relatively larger gain compensates for that. This gain is robust to different transaction costs, from 0 to 20\,bps. I run Hansen's SPA test twice at each window, with the skeleton control as the baseline. Over the full set of 5 orientation-aware allocators from the experiment plan, the null hypothesis (that the best candidate in the set has no performance gain over the baseline) is not rejected at the 504-day window ($p=\rsSpaDirWfivePre$). Over a narrowed set of 3 allocators (those that cover the key insertion points of information from the causal DAG into HRP), the SPA test marginally rejects ($p=\rsSpaDirWfive$). Once the 4 windows are pooled into a single SPA test,
    none of the results are significant in either the full set or the narrowed set.
  \item At the 252-day window, the skeleton-only allocator (\skelhrp{}) has a performance gain of $+0.022$. As stated above, I also test the performance improvement associated with a partial-correlation skeleton that was constructed without any causal discovery. I find that the DAG-derived skeleton outperforms that partial-correlation skeleton allocator by $+0.025$ ($p=0.008$), indicating that the causal discovery is truly the driver of the performance gain, rather than sparsity alone. This answers the first sub-question from
    Section~\ref{sec:question}.
  \item The performance gain associated with the DAG's edge orientations is due to the removal of the common market factor. The implied covariance from the DAG's structural equation model has two properties that are unrelated to edge direction but which nevertheless could potentially drive performance gain. The first is that it is a structured estimator with fewer parameters than the sample covariance it replaces, so it behaves like shrinkage. The second is that it has an independent-shock assumption which removes the common market factor. I test whether either of these properties drive performance gain.
  I find that a de-factored covariance, built without any graph, reproduces the gain of the edge-orientation-aware allocators at every window (the residual is between $-0.011$ and $+0.004$). On the other hand, Ledoit--Wolf shrinkage does not reproduce the performance gain (with \semcovhrp{}
    outperforming it by $+0.018$ to $+0.042$).
    This indicates that the gain from the SEM-implied
    covariance is due to its assumption of independent shocks, which
    removes the common market factor, rather than from the edge directions themselves.
    This answers the second sub-question of
    Section~\ref{sec:question}. The performance gains I observe are roughly half the
    minimum detectable effect, which bounds the null result, so the edge
    orientations are worth a gain in the Sharpe ratio of approximately $0$--$0.04$. I find that the effect also
    depends on the discovery method, as I find no effect when using VARLiNGAM graphs as an input, at any of the 4 windows.
\end{itemize}

In summary, the performance improvement from using a causal graph as an input to hierarchical allocation is stable across estimation windows. 
However, the component of the graph responsible for that improvement
is sensitive to the choice of window. Using Hansen's SPA to correct for the search space,
I find that my results are insignificant apart from on a narrowed family of allocators. See Chapter~\ref{chap:conclusion} for further details.

\chapter{Background and Related Work}
\label{chap:background}

This project is underpinned by three key areas of research: hierarchical portfolio allocation, applying causal graphs to investing, and causal discovery. 

\section{Hierarchical portfolio allocation}
\label{sec:hrp-theme}

In order to weight assets in a portfolio to minimise risk (variance) while maximising return, mean-variance optimisation \cite{markowitz1952portfolio} requires inverting the covariance matrix of asset returns.
For a large set of assets at a standard window size (around 1 year), that matrix is ill-conditioned, which means that the resulting weights are highly concentrated and unstable.
Hierarchical Risk Parity \cite{lopezdeprado2016hrp} sidesteps this matrix inversion problem. It uses a three-step approach to optimisation. First, it clusters assets by converting the
correlation matrix $\rho$ into a distance matrix $d$, where $d_{ij} = \sqrt{\tfrac{1}{2}(1-\rho_{ij})}$, and builds a binary tree (dendrogram) so closely related assets cluster together.
The second step is quasi-diagonalisation, where assets are ordered in the dendrogram's leaf order, so that large covariances sit near the diagonal.
Finally, assets are weighted in the portfolio using recursive bisection: the ordered list is split in half, the two halves are then weighted in inverse proportion to their cluster variances,
then each half of the list is recursed into. 
HRP is robust to ill-conditioning as no matrix is inverted.
This yields performance improvements over mean-variance and inverse-variance portfolios out of sample \cite{lopezdeprado2016hrp}.

Note that the allocation step (recursive bisection) takes in an ordered list, plus the variances from the clustering step. In standard HRP, that ordered list comes from a dendrogram, however this need not be the case: any procedure which produces
an economically meaningful asset ordering of the assets can be used in place of the clustering step.
In Section~\ref{sec:d2}, I do so using a causal-ordered bisection.
Also, as stated in Sections~\ref{sec:motivation} and \ref{sec:challenges}, HRP clustering requires symmetric matrices, which means
it cannot represent directed causal influence.
In Chapter~\ref{chap:sensitivity}, I address the problem of augmenting HRP with directional information.

There are several variants of HRP, including hierarchical
clustering-based asset allocation \cite{raffinot2017hierarchical} and nested clustered optimisation
\cite{lopezdeprado2020mlam}. Lohre, Rother and Sch\"afer
\cite{lohre2020hrp} extend HRP across multiple asset classes rather than just stocks, and allocate over risk factors. Also, instead of using correlation at the clustering step, they use a tail-dependence measure, measuring how assets co-move when they are performing poorly. This provides better assurance of portfolio performance during crises.

While I focus on HRP and its variants in this project, I want to verify whether my results hold across other hierarchical portfolio allocators.
One such allocator is Hierarchical Equal Risk Contribution (HERC)
\cite{raffinot2018herc}, which, rather than allocating by recursively bisecting the order of the leaves of the dendrogram, 
allocates based on the order the assets were clustered in.
Risk contributions are then equalised across the clusters it finds.
I test a HERC variant in Section~\ref{sec:decomposition}, and find mixed results.

While most of the HRP variants use the return correlation matrix as their input, Hierarchical Sensitivity Parity (HSP) \cite{rodriguez2023hsp} clusters assets on the similarity of their sensitivities to a set of common drivers instead. For each asset, a feed-forward neural network is created which uses $K$ macrofinancial drivers (such as interest rates, commodities, currencies, and volatility indices) to predict the asset's return.
The gradient of the neural network with respect to the macro drivers is the asset's sensitivity vector $s_i$. Then, to cluster the assets, the distance $\lVert s_i - s_j \rVert_2$ replaces the correlation distance.
The motivation is Reichenbach's common-cause principle \cite{rodriguez2023hsp,rodriguez2025causal, hitchcock2020reichenbach}: if the drivers are common causes of the assets, then the distance, measured between sensitivity vectors, measures how similarly assets are exposed to those causes.
Clustering on this sensitivity distance is therefore argues to diversify both systematic and idiosyncratic risk simultaneously.
HSP is therefore linked to the novel allocators in this thesis insofar as its clustering step does not just use correlation. However, it is not a causal allocator, as the drivers themselves are just selected on the basis of their cumulative correlation with the assets. Also, as the sensitivities are produced by a randomly initialised neural network (and may also be trained on GPUs whose threads finish at non-deterministic times), the allocation is not reproducible exactly.

Aside from simply improving the allocator mechanism as a whole, another way to improve portfolio optimisation is to improve the input. Linear shrinkage can reduce noise in the sample covariance matrix by punishing deviation from a structured target like an identity matrix, trading off a small bias for a large reduction in variance \cite{ledoitwolf2004}.
Another method for de-noising assets' co-movement is to use a single-factor model \cite{sharpe1963simplified} to remove the factor common to all assets' returns, and then using the resulting residual (de-factored) covariance.
This ``common-market factor'' is identified by the largest eigenvalue of the correlation matrix \cite{laloux1999noise}.
Both of these methods de-noise the input to the allocator without the need for any DAG. 
I therefore use these estimators in Chapter~\ref{chap:evaluation} to identify whether the performance improvements that I identify from the edge-orientation-aware allocators are due to the DAG itself or these de-noising estimators.

In the same chapter, I similarly use a graph-free simulacrum of the skeleton-only allocator to identify the drivers of its performance improvements. This graph-free control is a ``thresholded partial-correlation network''. 
The inverse of the covariance matrix (the precision matrix) gives the conditional dependence between pairs of assets. Thresholding it (using graphical lasso to sparsely estimate it \cite{friedman2008glasso}) yields a sparse, undirected network, with no need for causal discovery. Kenett et al.\ \cite{kenett2010partial} apply these thresholded networks to equities and find that they reveal a dominant financial sector that a standard correlation network does not find.

L\'opez de Prado has also done work on overfitting to backtests. This literature \cite{bailey2014deflated,lopezdeprado2023causal} focuses on establishing whether the performance of a particular allocator configuration has not just been cherry-picked out of many other allocator configurations attempted. 
The literature has produced metrics that account for this search space when evaluating performance on backtests.
First, the Probabilistic Sharpe Ratio \cite{bailey2012psr} replaces the
Gaussian sampling theory of the Sharpe ratio, which is untenable at the
excess kurtosis of ${\approx}\,\rsKurtosis$ I measure here, with a
version that corrects for the sample's skewness, kurtosis and length.
Second, the Deflated Sharpe Ratio \cite{bailey2014deflated} then raises the
benchmark from zero to the best Sharpe expected from $N$ independent
trials under the null of no skill, which directly discounts selection
bias. For comparing a family of strategies against a benchmark, White's
Reality Check \cite{white2000reality} and Hansen's SPA test
\cite{hansen2005spa} bootstrap the null hypothesis that no candidate in
the family beats the benchmark, and the Model Confidence Set
\cite{hansen2011mcs} returns the subset of strategies that are
statistically indistinguishable from the best. I apply this battery to
every claim in Chapter~\ref{chap:evaluation}. The Deflated Sharpe Ratio
corrects each headline Sharpe ratio for all \rsNtrials\ configurations I
evaluated, while the SPA and MCS run over the smaller family of
candidates relevant to each question. Several effects that look
important at first do not survive it, and I report those as well.

\section{Applying causal graphs to investing}
\label{sec:howard-theme}

The closest prior work to this project is Howard, Lohre and Mudde's application of DYNOTEARS to equities from the S\&P~500, re-estimated on a rolling basis \cite{howard2025causal}.
They find that causal networks carry information about macrofinancial regimes that correlation alone does not, such as the fact that denser networks are associated with recessions. 
The paper has two other findings that influence my research. First, they find that contemporaneous matrix from the structural model explains almost all of the structure, with the lagged matrices being almost empty, particularly after the first lag order. As a result, I only fit up to one lag in Section~\ref{sec:asset-graph}, and I only use the contemporaneous matrix as an input to my allocators.
The authors find that causal networks outperform correlation-based methods in some regards, but not consistently. I want to see whether a more comprehensive usage of causal graphs can yield a performance gain over correlational methods, and also whether that performance gain is due to the graph's skeleton or its edge orientations.
Also, they do not use the graph as a direct input into portfolio allocation, instead using it to represent similarity or compressing it into a single metric: this is a gap my research seeks to address.

\section{Causal discovery}
\label{sec:cd-tools}

There are two main types of causal discovery algorithms: score-based and constraint-based. Constraint-based algorithms, such as Peter-Clark and FCI, scale poorly as dimensionality increases, and rely on the faithfulness assumption (that statistical independence identified in the sample reflects true statistical separation -- d-separation). This assumption is weak in real-world markets, as counterbalancing effects can yield a negligible correlation between assets despite a true causal connection existing \cite{howard2025causal}. Even more modern constraint-based methods such as PCMCI \cite{runge2019pcmci} and PCMCI+ \cite{runge2020pcmciplus}, which are built for large time-series datasets, are unsuitable for this project: the former only tests lagged causal links, while the latter returns only a partially directed graph.
Score-based algorithms offer a better alternative. One example is NOTEARS \cite{zheng2018notears}, which turns graph discovery into a continuous optimisation problem by recasting the acyclicality requirement as a smooth constraint. DYNOTEARS \cite{pamfil2020dynotears} extends this to a structural VAR representation for time series data, and is the primary causal discovery algorithm I use.

However, NOTEARS methods do have a limitation regarding edge orientations: the fact that the least-squares score it uses to fit the DAG implicitly assumes that variables' shocks have equal variance. This assumption means NOTEARS tends to orient directed edges from lower-variance variables to higher-variance ones \cite{peters2014identifiability}. On that basis, Reisach, Seiler and Weichwald \cite{reisach2021beware} find that simply regressing each variable on higher-variance variables yields graphs that are approximately as good as NOTEARS' ones. Once the variables are standardised (each variable has its mean subtracted and is divided by its standard deviation, so it has mean 0 and variance 1), NOTEARS' accuracy falls to the level of PC. As a result of the above, I standardise the variables before fitting the discovery methods (see Section~\ref{sec:discovery-run}). Another paper by Reisach et al.\ also shows that, even after standardisation, ordering by explained variance ($R^2$) survives in NOTEARS graphs; I discuss this in Section~\ref{sec:believe}.

Another causal discovery family is LiNGAM \cite{shimizu2006lingam}, which uses non-Gaussian residuals to identify causal orderings for DAGs. VARLiNGAM \cite{hyvarinen2010varlingam} is its structural-VAR form, and serves as my robustness comparator to DYNOTEARS. Its identification rests on heavy-tailed residuals, which financial returns exhibit in short windows. However, at longer windows, this is not the case, as aggregation pulls residuals towards Gaussianity \cite{cont2001stylized}.

The final causal discovery algorithm I use is a VAR(1) coefficent matrix that has been ridge-regularised, which yields a Granger-causal
\cite{granger1969investigating} directed graph. 
This gives a reasonable directional ordering, 
but its shrunken one-lag coefficients are biased. 
As a result, I use it as a control to separate out the two aspects of orientation:
the directionality itself, and the magnitudes of the edges.

\section{Research gap}
\label{sec:gap}

Table~\ref{tab:gap} positions my research against prior work. HRP forms the baseline, \corrhrp{}, of my research. As mentioned above, HRP does not use directionality in the clustering step. HSP clusters on driver sensitivities rather than correlation, but selects the drivers themselves by correlation, and still uses a symmetric distance matrix as an input to the allocator. Howard et al.\ use causal discovery to identify DAGs but do not use them directly for portfolio allocation. None of them can separately attribute the value of the skeleton and the edge orientation of a graph, as none of them set hierarchical portfolio weights from a causal graph of assets in the first place. I do so in Chapters~\ref{chap:sensitivity} to \ref{chap:evaluation}.

Allocating from a graph of assets is not itself novel: Mantegna \cite{mantegna1999hierarchical} creates a minimum spanning tree (MST) from the correlation matrix, and uses that to create a hierarchical clustering of assets. Tumminello et al.\
\cite{tumminello2005pmfg} extend this by using a planar maximally
filtered graph (PMFG), which keeps more edges.
Subsequent research along these lines found that allocating portfolio weight to the periphery of the network outperforms allocating weight to central nodes \cite{pozzi2013spread,peralta2016network}, as the latter are connected to everything and 
so diversifies least. 
This research motivates the importance of the skeleton: \skelhrp{}, the skeleton-only
allocator of this thesis, likewise builds a graph over the assets and allocates down its
structure, but its graph comes from causal discovery rather than from
filtering a correlation matrix. 
Directed-graph allocation is also
not unprecedented: Granger-causality networks over financial
institutions are an established tool for measuring systemic risk
\cite{billio2012econometric}, and prior research has set
portfolio weights directly from such directed networks
\cite{vyrost2019network}. 
However, no prior work sets hierarchical portfolio weights from a discovered score-based causal graph, nor decomposes the allocation value of such a
graph into its skeleton and its edge orientations. This thesis addresses that gap.

\chapter{Discovering the Graph}
\label{chap:discovery}

This chapter addresses the first of the three challenges described in
Section~\ref{sec:challenges}: attributing performance gains to different
aspects of the causal graph. 
I describe the pipeline that produces the fixed graph that feeds into every allocator at every monthly rebalance of the backtest.
Section~\ref{sec:data} describes the data,
Section~\ref{sec:discovery-run} describes the rolling discovery and the

\section{Data}
\label{sec:data}

The full S\&P~500 is too large to run causal discovery over given my compute constraints. I therefore construct a subset of the 99 largest assets; my initial target was the S\&P~100, but historical data is paywalled. Instead, I use the largest market-cap assets from the S\&P~500 at each rebalance, and take the union across those rebalances to get set of 99 assets over 2007--2024. Naturally, this is just an approximation of the official index.
The full list is located in Appendix~\ref{app:universe}.
I use CRSP via WRDS for share prices and numbers. When an allocator delists, CRSP records a final delisting return, which measures what a
shareholder recovered relative to the last quoted price. For an
involuntary delisting, such as a bankruptcy or a removal from the
exchange, that return is generally a loss. I do not account for this loss; instead, an asset
that delists mid-sample just leaves the panel at its last quoted
price, as if the position had been sold there.
This biases reported performance upwards slightly, however it does not affect pairwise contrasts between allocators as they are all treated the same way.
Assets that listed after 2007 are made eligible to be invested in by the allocators once they are listed for the full duration of an estimation window.

I run causal discovery on the joint panel of the 99
assets and 33 plausibly exogenous macro-financial series (``drivers'') from FRED and
Yahoo Finance, including Treasury rates and slopes, credit spreads, commodities, FX
pairs, volatility indices, and international-equity ETFs. 
This means that the asset-to-asset submatrix is estimated conditional on the macro drivers, which removes any co-movement explained by the drivers. I exclude series that are clearly non-exogenous, such as sector ETFs, US index returns and factor portfolios.

SVARs require weakly stationary inputs, so I transform time series accordingly: log-returns for price-like series, first differences for yields and spreads, year-on-year changes for monthly macro levels (which also removes seasonality), and no transform for the volatility indices, which are already stationary. 
The same transformations are applied in every estimation window to ensure a consistent definition for the variables.
I then check stationarity with ADF and KPSS tests. 

\section{Discovery and the directional prior}
\label{sec:discovery-run}

I use DYNOTEARS as my primary causal discovery method because it meets three key requirements.
First, the method must be scalable to process the ${\sim}132$-variable joint panel in reasonable time, across every monthly rebalance.
Second, it must be able to accept the ``directional prior'' ex ante, rather than removing asset-to-driver edges post hoc. This directional prior is that macro drivers can cause assets, but not vice versa, as the drivers are supposed to be exogenous. Thus, there are no edges from assets to drivers.
Third, the method must return a DAG. The allocators I use (see Chapter~\ref{chap:sensitivity}) propagate shocks along every directed path in the graph. If the graph is acyclic, I can sum the results exactly (Section~\ref{sec:sem}). 
A DAG also has a topological order, which I use in place of a clustering dendrogram in the ordering-based allocators I develop.
As mentioned above, VARLiNGAM's main weakness is that, at longer estimation windows, its identifying assumption of heavy-tailed residuals weakens. Ridge-Granger likewise has a weakness in that it does not guarantee an acyclic graph, and its coefficients are not structural effect sizes (Section~\ref{sec:comparators}).

At each rebalance date $t$, I fit DYNOTEARS on
a joint panel of drivers and assets $X=[\,D \mid A\,]$, with the rows representing the trading days in the estimation window
(note there are 4 different estimation window sizes, varying from 189 to 504 trading days -- see Chapter~\ref{chap:evaluation}), with a one-day lag. 
As mentioned in Section~\ref{sec:howard-theme}, lags over 1 are negligible at these horizons.
I standardise all the variables in each window because, as mentioned in Section~\ref{sec:cd-tools}, NOTEARS methods are scale dependent. I apply the same standardisation for the fits across the other two comparator discovery methods too, and convert the graph back to return units in Section~\ref{sec:sem}.
This fitting yields two matrices: a contemporaneous matrix $W$ and a lagged matrix $A_1$, both over the joint variable set.
Throughout the report, $M[i,j]$ defines the effect of variable $i$ on variable $j$.
I list the hyperparameters in Appendix~\ref{app:tables}.

I enforce the directional prior by populating DYNOTEARS' list of forbidden edges with all asset-to-driver links at each lag, forcing them to zero.
VARLiNGAM takes in a similar list of forbidden edges, so no forbidden edges enter the contemporaneous block. However, its pruning step refits the lagged block without referencing that list, so I simply set any asset-to-driver edges to zero after the fact.
I also test whether the prior actually has a measurable effect by refitting DYNOTEARS with and without the prior on 6 windows; 2008, 2011, 2014, 2018Q4, 2020 and 2022. I chose them because they span different macrofinancial regimes. I find that the prior is indeed effective: without it, the economically implausible asset-to-driver edges represent 36--48\% of the total weight running between the drivers and the assets.
Calculating the total difference between the fitted DYNOTEARS matrix with and without the directional prior reveals that the legitimate coefficients differ by 52--72\% of the total weight of the driver-to-asset block.
The prior also affects the relative importance of drivers. Ranking drivers by the total weight of their edges to assets, I find the intersection over union between the rankings with and without the prior ranges from $0.58$ to $0.91$, across the 6 windows and across cut-offs at the top 10, 15 and 20 drivers. At the top 15, the worst window shares only 11 of the 15 drivers, so 4 of the most influential drivers change identity. The 2008 and 2022 stress windows are the two lowest at the top 15 and the top 20, and at the top 10 they tie with 2018 for the lowest, so this pattern does not depend on where I cut the ranking (see Figure~\ref{fig:prior}).
The above results clearly point to the importance of the prior.

\section{Extracting the asset graph}
\label{sec:asset-graph}

The fixed-graph ablation requires each allocator to receive the same graph. I therefore create a single function to extract the graph. 
At each rebalance, it takes the asset-to-asset submatrix from the fitted contemporaneous matrix, and verifies it is acyclic. I also apply a magnitude threshold, pruning any edges with weights below a certain value: by default, this threshold is $0$ (no edges are pruned), but I sweep through multiple values in Section~\ref{sec:decomposition}. 
The function also computes structural residual variances for each asset on
the fit window. This is required by the covariance from the structural equation model (SEM) -- see Section~\ref{sec:d-family}.

Across the different estimation window lengths (from 189 to 504 days), the
DYNOTEARS asset graphs average ${\sim}614$--$673$ directed edges (a
density of $6.3$--$6.9\%$ of the possible ordered pairs). Their mean
longest directed path is ${\approx}50$ nodes out of 99, which suggests
deep chains of influence rather than a shallow hub-and-spoke structure.
Therefore, the graphs contain substantial orientation structure for the
orientation-aware allocators to harness. Whatever the evaluation finds,
it will not be because the graphs are trivially symmetric. One
diagnostic is missing: I did not measure month-to-month edge persistence
(Section~\ref{sec:limitations}). The same diagnostic signals a
comparator limitation. VARLiNGAM's unpruned $B_0$ saturates to $32\%$
density at the 189-day window, where there are $n=189$ observations
against $d=132$ variables, whereas DYNOTEARS' $\ell_1$ penalty holds
density steady.

One obvious objection must be addressed directly: what can ``credible''
mean without ground truth? No true causal graph of the market is
available, so the discovered graphs cannot be scored against an answer
key. For that reason, I validate the pipeline on everything that can be
checked. The directional prior has a quantified effect (above). The
graphs are structurally non-degenerate, with depth for the treatments to
exploit. Discovery is deterministic, so the graphs are stable facts
about the data and not artefacts of a particular run. Disagreement
between discovery methods is treated as a diagnostic rather than
averaged away (Section~\ref{sec:comparators}). Most importantly, the
graphs are judged by the controlled downstream ablation of
Chapters~\ref{chap:sensitivity}--\ref{chap:evaluation}. This is a
task-based test, and it is the only economically meaningful one. I
therefore claim that the graphs are useful and reproducible. I do not
claim that they are true.

\section{Controls on the orientation content}
\label{sec:comparators}

The research question depends on what the edge orientations contribute,
so the design carries two additional graph sources that perturb exactly
that ingredient. Both feed the same extraction function, so every
allocator runs unchanged on them.

VARLiNGAM \cite{hyvarinen2010varlingam} supplies differently identified
orientations. Its instantaneous matrix $B_0$ is identified through
non-Gaussianity rather than through a score. The causal order of LiNGAM
makes the asset block a DAG by construction. Its identification
assumption (heavy-tailed residuals) becomes weaker mechanically at
longer windows. This is the window fragility that
Section~\ref{sec:cd-tools} anticipated, and
Chapter~\ref{chap:evaluation} observes it.

Ridge-Granger provides orientations with degraded magnitudes. It is a
ridge-regularised VAR(1) on the asset panel, computed in closed form,
with $M[i,j] = |{\rm coef}(x_{i,t-1}\!\to\!x_{j,t})|$. I threshold it in
each window to match the edge density of the paired DYNOTEARS graph, so
that the comparison is at like-for-like sparsity. While its lagged,
shrunken coefficients still order the assets directionally, they are not
structural effect sizes. It is also not guaranteed to be acyclic, which
the allocators take care of explicitly (a truncated Neumann series for
the total effects, and minimal feedback-arc removal prior to topological
ordering).

Thus, the two controls split ``orientation'' into its parts. If an
effect requires DYNOTEARS' particular arrows, VARLiNGAM should not
replicate it. If, however, an effect requires trustworthy edge
magnitudes rather than arrows alone, then on ridge-Granger graphs the
ordering-based allocators should survive where the shock-propagation
allocators fail. This is tested in Section~\ref{sec:decomposition}. (I
also examined a non-linear extension, NTS-NOTEARS
\cite{sun2023ntsnotears}, at reduced scale, and leave it as future work;
see Section~\ref{sec:future}.)

\section{Engineering for tractability and reproducibility}
\label{sec:cache}

Two pieces of engineering underpin the credibility of every number in
Chapter~\ref{chap:evaluation}.

The first is the discovery cache. The graph fit is the dominant cost:
roughly 4 minutes per window at $d\approx132$, and about 15 hours per
backtest. However, the fit depends only on the window data and the
discovery hyperparameters, and on nothing downstream. A content-keyed
disk cache therefore lets every configuration at a given window reuse
one fit. The full ablation grid was run against 1{,}684 cached graph
fits with a verified 100\% hit rate and zero refits, at approximately 40
seconds per backtest. The cache also upholds the ablation's premise.
Allocators cannot see different graphs, since there is exactly one graph
for each (method, window, data) key. The mechanics of the cache are
documented in Appendix~\ref{app:tables}.

The second is a data-determinism defect, which I identified and fixed.
Building the cache revealed a latent reproducibility bug: one driver
series (the emerging-markets ETF EEM) was silently re-downloaded on
every call. The resulting micro-jitter, amplified by the non-convex
DYNOTEARS optimiser, made the pipeline irreproducible at the bit level.
Two conclusions I had drawn in the project's first phase were
invalidated by the fix. That first phase was an exploratory precursor on
the same panel and protocol. It evaluated earlier causal allocators,
including the skeleton-only allocator (\skelhrp{}) that this study
measures orientation against. Its configurations are counted among the
\rsNtrials\ configurations that the Deflated Sharpe ratio of
Chapter~\ref{chap:evaluation} adjusts for, and its committed skeleton
result is the target of the replication gate described in
Section~\ref{sec:ablation-design}. All numbers in this report come from
the corrected, deterministic pipeline. Two independent runs now generate
identical windows, weights and NAVs, verified end-to-end by that
replication gate. A result that does not survive a determinism fix was
never real, so I treat reproducibility as a prerequisite rather than an
afterthought \cite{lopezdeprado2023causal}. Appendix~\ref{app:tables}
documents the mechanism of the defect, and the observation that
VARLiNGAM's ICA-based fits were robust to the same jitter.

\chapter{From Graph to Weights}
\label{chap:sensitivity}

This chapter addresses the second obstacle of
Section~\ref{sec:challenges}: getting a hierarchical allocator to use
edge direction at all. I describe a family of allocators that all share
the same per-window graph. Of these, two only see the skeleton of the
graph, while the other three can see its edge orientations. Comparing
them is the fixed-graph ablation, in which the only distinction is
orientation. This family is what meets the second premise of
Section~\ref{sec:question}: without it, the value of orientation cannot
be measured at all. Section~\ref{sec:symm} formalises the problem.
Section~\ref{sec:sem} derives the total-effect matrix and the implied
covariance that the orientation-aware allocators rely on.
Sections~\ref{sec:controls}--\ref{sec:d-family} define the allocators,
and Section~\ref{sec:ablation-design} sets out the ablation design.

\section{The symmetric-clustering problem}
\label{sec:symm}

Hierarchical allocation (Section~\ref{sec:hrp-theme}) requires a
symmetric, non-negative distance matrix. A causal graph is asymmetric by
design, and this asymmetry is the object of study. While symmetrising
the adjacency as $\tfrac{1}{2}(|M| + |M^\top|)$ is the common first
approach, it would remove the very orientations the research question is
concerned with. Symmetric clustering cannot preserve orientation, so the
allocation steps themselves need to be adjusted. The aim is therefore to
construct allocation steps that take the directed matrix natively, with
everything else kept fixed to the greatest extent possible, rather than
forcing $M$ into the existing symmetric input. That way, any difference
in performance can be attributed to orientation, and to nothing else.
The two observations in Section~\ref{sec:hrp-theme} show how. First,
HRP's dendrogram is only used to produce a leaf ordering for recursive
bisection, and a DAG has a natural ordering for free. Second, HRP's
bisection step uses cluster variances from a covariance matrix, and a
DAG implies one.

\section{The structural model: total effects and the implied covariance}
\label{sec:sem}

Both DYNOTEARS' $W$ and VARLiNGAM's $B_0$, restricted to the asset block
and written in the $i\to j$ convention, define a linear structural
equation model (SEM) \cite{wright1934path,bollen1989sem}
\begin{equation}   (I - M^\top)\, x = \varepsilon
\qquad\Longrightarrow\qquad   x = (I - M^\top)^{-1} \varepsilon \;=:\;
B\,\varepsilon,   \label{eq:sem} \end{equation} with $x$ being the
vector of (standardised) asset returns and $\varepsilon$ the vector of
structural shocks. As the asset block is a DAG, its adjacency matrix is
nilpotent. This implies that the total-effect matrix $B = \sum_{k\ge 0}
(M^\top)^k$ terminates in at most $N$ terms and exists exactly, without
the need for a spectral-radius assumption. The entry $B_{ij} = \partial
x_i / \partial \varepsilon_j$ captures the total effect of a unit shock
at asset $j$ on asset $i$ along all directed paths. It is the Leontief
inverse of input--output economics. Its asymmetry is where orientation
enters allocation natively. (For the ridge-Granger control, which is not
a DAG, I approximate $B$ by the truncated series with a spectral-radius
guard.)

The SEM of Eq.~\eqref{eq:sem} implies a covariance. Let
$\Sigma_\varepsilon = \operatorname{diag}(\sigma^2_{\varepsilon,i})$.
The diagonal form is the SEM's own independent-shocks assumption.
Estimating a dense $\Sigma_\varepsilon$ would reintroduce sample
correlation into a treatment that is meant to isolate the graph. The
SEM-implied covariance in return units is thus \begin{equation}
\Sigma_{\mathrm{SEM}}   \;=\; D_\sigma \big( B\, \Sigma_\varepsilon\,
B^\top \big) D_\sigma ,   \label{eq:sigma-sem} \end{equation} where the
shock variances are estimated from the fit window's structural residuals
$E = \tilde{X} (I - M)$, where $\tilde{X}$ is the standardised
fit-window panel, and $D_\sigma$ converts from the standardised units
the graph was fitted in back to return units. A note on the name:
$\Sigma_{\mathrm{SEM}}$ is the covariance of the observables that the
structural model implies (the $\Sigma(\theta)$ of SEM, or the reduced
form in SVAR terminology), while the diagonal $\Sigma_\varepsilon$ above
is the structural shocks' own covariance. The transformation back to
return units is necessary: recursive bisection compares cluster
variances, and omitting $D_\sigma$ would silently make all asset
volatilities equal. Two caveats apply. The asset-block SEM marginalises
over the drivers, so $\varepsilon$ absorbs driver-explained variance and
its diagonality is an approximation. Also, I project
$\Sigma_{\mathrm{SEM}}$ to the nearest positive semi-definite (PSD)
matrix and add a small ridge, so that dense stress-window graphs cannot
produce a singular input.

\section{The controls: correlation and skeleton}
\label{sec:controls}

The correlation baseline, \corrhrp{}, is textbook HRP
\cite{lopezdeprado2016hrp}: the distance
$\sqrt{\tfrac{1}{2}(1-\rho_{ij})}$ on the estimation window's sample
correlation, with the sample covariance for bisection. It is
graph-blind, which I verify by unit test (changing the graph cannot
change its weights), and every performance gain reported here is
measured relative to it.

The skeleton control, \skelhrp{}, substitutes the graph for the
correlation matrix, but in a symmetric way, so that it sees only the
skeleton. Each asset is embedded by its edge profile $e_i =
[\,M_{i\cdot},\, M_{\cdot i}\,]$, the clustering distance is $D_{ij} =
\lVert e_i - e_j \rVert_2$, and bisection uses the sample covariance.
This embedding is provably invariant to reversing every edge at once, as
transposing $M$ swaps the two halves of every $e_i$, which leaves every
pairwise distance, and thus the dendrogram and the weights, unchanged. A
unit test ensures this property. That is the extent of the guarantee.
Since $e_i$ keeps outgoing and incoming edges in separate halves,
reversing a single edge can move mass between the halves and change the
distances. \skelhrp{} thus retains each asset's profile of source and
sink roles, which is information the undirected skeleton alone does not
contain. The control with the stronger guarantee is \undirhrp{} below,
and Chapter~\ref{chap:evaluation} measures the decomposition against
both. \skelhrp{} coincides with the skeleton allocator that I assessed
in the first phase of the project (Section~\ref{sec:cache}), which
allows me to verify the new harness against a committed historical
result (Section~\ref{sec:ablation-design}).

The second control, \undirhrp{}, is a second symmetrisation.
Hierarchical clustering requires a symmetric distance and $M$ is not
symmetric, so building a skeleton control involves a choice of
symmetrisation, and this choice is not unique. If the measured
contribution of the skeleton depended on which symmetrisation I chose,
it would be a statement about the recipe, and not about the skeleton.
\undirhrp{} is therefore a control on the control. It is the same
pipeline, but with the $\tfrac{1}{2}(|M|+|M^\top|)$ distance, so that
two assets are close when a strong link joins them rather than when
their edge profiles match. Of the two, \undirhrp{} has the stronger
orientation-blindness guarantee. $\tfrac{1}{2}(|M|+|M^\top|)$ is a
function of the undirected weighted adjacency alone, so it is invariant
to the reversal of any single edge, while \skelhrp{}'s embedding is
invariant only to the reversal of all edges simultaneously. Comparing
the two tests whether ``the skeleton'' has been accidentally equated
with one particular symmetrisation. Chapter~\ref{chap:evaluation}
reports where they differ.

\section{The orientation-aware family}
\label{sec:d-family}

Section~\ref{sec:symm} left hierarchical allocation with exactly two
moving parts, which restricts the design space. The clustering step
exists only to create an ordering, while the allocation step only uses a
covariance. Nothing else passes between the two steps: recursive
bisection takes the ordering and the covariance and nothing more, and it
splits the ordered list by position rather than along the dendrogram's
own branches. A causal graph therefore has exactly two entry points into
HRP, the ordering and the covariance. Crossing them enumerates the
family completely (Table~\ref{tab:crossing}).

Two observations follow from the rows. The first row retains the
clustering step but feeds it a graph-derived distance. The second row

not require a dendrogram to produce an ordering. Thus, the distinction

single aspect: \semcovhrp{} in the covariance alone, \topohrp{} in the
ordering alone, and \toposemcovhrp{} in both. This allows the results
chapter to identify not only whether orientation carries value, but also
where. All three are long-only, fully invested, deterministic and
seed-free. All take the same $(M,\ \text{returns window})$ inputs as the
controls. None has an analogue in the literature on hierarchical
allocation.

The first treatment, \semcovhrp{}, takes the SEM-implied covariance at
the allocation step. Its clustering is as in \skelhrp{}. I deliberately
fix the ordering at the skeleton, so that $\semcovhrp{}-\skelhrp{}$
isolates the effect of orientation on the allocation step alone.
Recursive bisection, however, allocates on $\Sigma_{\mathrm{SEM}}$ of
Eq.~\eqref{eq:sigma-sem} instead of the sample covariance. Orientation
enters through the asymmetric propagation of shocks in $B$.

The remaining two treatments, \topohrp{} and \toposemcovhrp{}, use
causal-ordered bisection. \label{sec:d2} Here the clustering step is
entirely removed. HRP's dendrogram exists solely to produce a
quasi-diagonalising leaf order, and a DAG can provide an order natively.
I sort the assets from upstream to downstream using a topological sort
of $M$. I break ties deterministically by total downstream influence
$\sum_r |B_{ri}|$ and, where ties persist, by name. The existing
recursive bisection then runs on that order, with the sample covariance
(\topohrp{}) or with $\Sigma_{\mathrm{SEM}}$ (\toposemcovhrp{}). This is
the most direct answer to the problem that one cannot cluster on an
asymmetric matrix: I do not cluster at all. The ablation's own tests
uncovered one subtlety which should be recorded. Recursive bisection is
mirror-invariant: reversing the leaf order yields the same partition
tree. This means that \topohrp{} responds to orientation through the
partition structure the order induces, and not through the
upstream/downstream direction itself.

\section{The fixed-graph ablation}
\label{sec:ablation-design}

The experimental design is what transforms the family into an answer to
the research question.

The design rests on one rule. At each rebalance, the extraction function
of Section~\ref{sec:asset-graph} provides the same graph $M$ to all the
allocators in Table~\ref{tab:variants}. The other components are shared
code: the universe, the calendar, the costs, the covariance-estimation
window, and the allocator internals downstream of the distance,
covariance and ordering choice. Thus, the only factor that changes is
orientation, and the decomposition is comprised of two differences with
a common reference: $\skelhrp{}-\corrhrp{}$ (the skeleton) and
$\oriented{}-\skelhrp{}$ (the orientations). When the two are added, the
common reference cancels,
\begin{align*}
  (\skelhrp{}-\corrhrp{}) + (\oriented{}-\skelhrp{}) \\
  = \oriented{}-\corrhrp{},
\end{align*}
so the total causal-graph gain is attributed with no remainder.

The reported grid employs 5 graph-consuming allocators $\times$
\{DYNOTEARS, VARLiNGAM\} $\times$ \{189, 252, 378, 504\}-day windows, in
conjunction with the ridge-Granger control, a sparsity sweep and a cost
sweep. The evaluated grid is wider. The original plan for the experiment
included 7 allocators. During the evaluation, I added mechanism controls
(two direction-free covariance controls and a graph-free
partial-correlation skeleton control), a second hierarchical family
(HERC), and two simple benchmarks (equal weight and inverse variance).
The narrowing to 5 allocators, and the provenance of every extension,
are stated in Section~\ref{sec:believe}, and every evaluated cell is
included in the \rsNtrials\ configurations that the Deflated Sharpe
ratio corrects for. The window axis is a design variable in its own
right. The sample moments each allocator uses deteriorate in opposite
directions, through estimation noise as the window shrinks and through
staleness across regimes as the window grows. Tracing the decomposition
over windows from 9 months to 2 years therefore tests where each type of
graph information adds value. I report each cell of the grid. At the
shortest window, the discovery fit has $n=189$ observations against
$d=132$ variables. This is valid ($n>d$) but thin, and I carry this
caveat through to the results.

Three verification gates had to pass before any result was read. The
first is the unit-test gate: 60+ tests, developed prior to running the
grid. These verify the orientation-blindness of the controls, the
orientation-sensitivity of each treatment, total-effect and
SEM-covariance identities against hand-computed cases, and
topological-order properties on random DAGs. The cache gate requires
that every graph fit is verified as a cache hit with zero refits, so no
allocator can have seen a different graph. The replication gate requires
that \skelhrp{}, run through the new harness, exactly reproduces the
committed first-phase bundle. This verifies both that the new machinery
is faithful and that the entire pipeline is deterministic.
Appendix~\ref{app:tables} records the figures for these gates.

\chapter{Decomposing the Gain}
\label{chap:evaluation}

This chapter deals with the third challenge of
Section~\ref{sec:challenges}: statistical inference at realistic effect
sizes. The effects of interest span 0.01 to 0.03 Sharpe over around 18
years of data, spread across \rsNtrials\ assessed configurations, so a
single pairwise $p$-value on its own means little.
Section~\ref{sec:method} fixes how I measure the performance gain.
Section~\ref{sec:r1} examines the first premise, whether the causal
graph improves on the correlation matrix at all.
Section~\ref{sec:decomposition} decomposes the gain into the skeleton
and the edge orientations, and assesses the robustness of the
decomposition to the free parameters of the design.
Section~\ref{sec:believe-rigour} adjusts each claim for the search over
configurations, Section~\ref{sec:oos} examines the results out of
sample, and Section~\ref{sec:believe} outlines the threats to validity.

\section{Measurement protocol}
\label{sec:method}

The measurement protocol is the same for every configuration: each runs
the identical walk-forward backtest. It employs the fixed universe of 99
names, monthly rebalancing over 2007--2024, estimation windows of 189,
252, 378 and 504 trading days for both the graph fit and the sample
covariance, weights held for 21 trading days, and transaction costs of
5\,bps per unit of one-way turnover (swept over $\{0,5,10,20\}$\,bps).
There are 215 rebalances at every window, from 2007-01 to 2024-11, on
an identical daily calendar. The longer burn-in periods of the 378- and
504-day windows mean that the first 6 and 12 of those rebalances,
respectively, fall back to equal weight, identically for every allocator
at that window, so 209 and 203 rebalances are graph-fed. Every contrast
at those two windows is therefore measured on a series whose opening 6
or 12 months are shared by both arms, which dilutes it slightly towards
zero. ``Performance'' always refers to the
out-of-sample, net-of-cost, annualised Sharpe ratio of daily portfolio
returns. I report this metric along with CAGR, maximum drawdown and mean
turnover (Table~\ref{tab:return-terms} in Appendix~\ref{app:tables}
provides these statistics for the headline configurations). No in-sample
number appears anywhere in this report, and gross figures appear only as
the zero-cost arm of the cost sweep.

Inference follows a fixed battery. For pairwise contrasts, I use the
Politis--Romano stationary block bootstrap \cite{politis1994stationary}
with 10{,}000 resamples and a mean block length of 21 days. It resamples
the joint return panel, so cross-strategy correlation is maintained.
Daily returns show heavy non-normality (excess kurtosis
${\approx}\,\rsKurtosis$; Figure~\ref{fig:retdist},
Appendix~\ref{app:tables}), and I assessed \rsNtrials\ configurations in
total. (This count deliberately includes byte-identical duplicates,
which is the conservative choice.) This means I never take pairwise
$p$-values at face value. Every claim is re-tested by the battery of
Section~\ref{sec:believe-rigour}: the Probabilistic and Deflated Sharpe
ratios \cite{bailey2012psr,bailey2014deflated}, with the DSR correcting
for all \rsNtrials\ configurations; Hansen's SPA \cite{hansen2005spa},
the studentised successor of White's Reality Check
\cite{white2000reality}, for each comparison of a family of allocators
against a baseline; and the $90\%$ Model Confidence Set
\cite{hansen2011mcs}. Both family-wise tests take the daily net return
as the performance measure (the loss is its negative), so their null
hypotheses concern mean return rather than the Sharpe ratio. Every
allocator in the families is long-only and fully invested on the same
universe, with closely matched volatilities, so the two orderings
coincide here, but the family-wise $p$-values are on returns and should
be read as such. Regimes are defined by NBER recession dates and by the
top and bottom VIX quintiles.

Stability is guaranteed by construction. Each allocator in this study is
deterministic and seed-free. Two independent end-to-end runs yield
identical graphs, weights and NAVs, a property verified by the
replication gate (Section~\ref{sec:ablation-design}). All values
appearing in this chapter come from the pipeline of
Section~\ref{sec:cache}.

\section{Premise 1: the causal graph against the correlation matrix}
\label{sec:r1}

The first premise asks whether there is any gain to decompose at all.
The like-for-like comparison is the graph-blind \corrhrp{} baseline
versus the causal-graph allocators on the same machinery, at all 4
windows. The baseline Sharpe ratios are $\rsCorrSharpeWone$,
$\rsCorrSharpe$, $\rsCorrSharpeWthree$ and $\rsCorrSharpeWfive$ for the
189-, 252-, 378- and 504-day windows, respectively. For the
decomposition, the reference treatment is \semcovhrp{}, the allocator
that uses the implied covariance of the DAG at the allocation step and
differs from the skeleton control only in that step. It yields a total
performance gain over the baseline of $+0.018$, $+0.031$, $+0.030$ and
$+0.032$ for the respective windows ($p=0.43$--$0.11$;
Table~\ref{tab:decomp}), and \toposemcovhrp{}, which also uses the DAG's
topological order at the ordering step, reaches $+0.036$ at the 504-day
window. There are 20 comparisons between DYNOTEARS-fed allocators and
\corrhrp{} (5 graph-consuming allocators at 4 windows), and 19 of these
comparisons are positive; the exception is \skelhrp{} at the 189-day
window. 17 of the 20 VARLiNGAM comparisons are positive.

This consistency should be interpreted as robustness rather than as
significance. Since the cells share one return panel, overlapping
windows and common machinery, they are far from independent draws, and
no sign-count translates into a valid $p$-value. What it does show is
that the direction of the gain is not contingent on the choice of
allocator, discovery method or window. No cell is individually
significant, and I leave inference under the panel's dependence
structure to the tests of Section~\ref{sec:believe-rigour}. In short,
those tests run Hansen's SPA test, whose null hypothesis is that no
allocator in the family outperforms \corrhrp{}, on two families at each
window, with the candidates drawn from both discovery methods. For the
full family of 7 allocators, the null is not rejected at any window. For
a narrowed family of 5 allocators, which I fixed after these results
were seen, it is rejected only at the 378-day and 504-day windows. The
first premise therefore rests on the sign consistency and
the stable total, and not on significance after accounting for the
search: the causal graph comes out modestly ahead of the correlation
matrix at every window. The decomposition that follows does not stand or
fall with this premise in any case. It compares the graph-fed allocators
with one another on identical inputs, so it remains informative about
where any gain, regardless of its magnitude, comes from.

In return terms, the gain is $+0.4$ to $+0.7$ percentage points of net
CAGR per year ($5.62\%$ against $4.97\%$ for \semcovhrp{} versus the
baseline at 252 days; Table~\ref{tab:return-terms}). Two simple
benchmarks give a sense of the absolute levels. Equal weight has a
Sharpe ratio of $\rsEwSharpe$, and inverse variance has $\rsIvpSharpe$
at 252 days (Table~\ref{tab:return-terms}). Every HRP allocator on
DYNOTEARS and VARLiNGAM graphs outperforms equal
weight at every window, although the smallest margin, for \semcovhrp{}
on VARLiNGAM graphs at 189 days, is $0.0002$. The statement does not
extend to the HERC family or to the ridge-Granger and Ledoit--Wolf
cells, several of which fall below equal weight
(Appendix~\ref{app:tables}). The correlation baseline itself lags behind
inverse variance at 3 of the 4 windows. The thesis's claims are
contrasts within the family.
The benchmarks indicate that the family's absolute edge on this universe
is modest.

\section{The decomposition: skeleton versus orientation}
\label{sec:decomposition}

\subsection{The decomposition across estimation windows}

Figure~\ref{fig:gradient} is the thesis's central result: the two
components of the decomposition traced across the 4 estimation windows.
Table~\ref{tab:decomp} gives the numbers, Figure~\ref{fig:heatmap} the
full allocator-by-method matrix, and Figure~\ref{fig:decomp}
(Appendix~\ref{app:tables}) the per-window levels. Three features carry
the answer to the research question. First, the total performance gain
of the causal graph is stable: $+0.018$ to $+0.032$ for \semcovhrp{} at
every window, rising to $+0.036$ for \toposemcovhrp{} at 504 days.
Second, the contribution of the skeleton (\skelhrp{} minus \corrhrp{})
is hump-shaped. It is $-0.003$ at 189 days, peaks at $+0.022$ at 252
days and falls to $+0.009$ at 504 days, and it is never individually
significant ($p \geq 0.14$). Third, the edge orientations' contribution
(\semcovhrp{} minus \skelhrp{}) is positive at every window and
U-shaped: $+0.021$ at $p=0.08$, $+0.009$ at $p=0.45$, $+0.012$ at
$p=0.31$, and $+0.023$ at $p=0.048$. It is largest at the two extremes
and smallest where the skeleton peaks, and 11 of the 12 DYNOTEARS
orientation contrasts across the grid are positive
(Figure~\ref{fig:forest}). The two components are roughly complementary,
which explains why the total is flat while its composition shifts.
Hansen's SPA test, run over the family of orientation-aware allocators
under both discovery methods against \skelhrp{}, rejects the null that
none of them outperforms \skelhrp{} only at 504 days, which is also
where the pairwise effect peaks, and only for the narrowed family of 3
orientation-aware allocators.
Section~\ref{sec:believe-rigour} reports both families and sizes that
rejection.

The contributions above are measured against \skelhrp{}, and they depend
on that choice of skeleton control. Measuring them against \undirhrp{}
instead, the symmetrisation with the stronger orientation-blindness
guarantee (Section~\ref{sec:controls}), gives different results. The
skeleton contribution becomes flat ($+0.022$, $+0.018$, $+0.024$,
$+0.019$ across the 4 windows). The orientation contribution becomes
$-0.003$, $+0.013$, $+0.006$ and $+0.012$ for \semcovhrp{}, and
$-0.003$, $+0.008$, $+0.010$ and $+0.016$ for \toposemcovhrp{} (point
estimates, not formally tested). Both controls indicate that the
orientations' contribution is positive at every window from 1 year out,
and largest at the longer windows. They disagree at 189 days, where
\undirhrp{} beats \skelhrp{} by $+0.025$ ($p=0.013$), the largest
discrepancy between the two skeleton controls at any window. This
suggests that at
the shortest window, the choice of symmetrisation is as important as
orientation itself, and I therefore read the 189-day column with that
caveat throughout. The hump and the U are descriptions relative to
\skelhrp{}. The findings that hold under both controls are the
flat-to-positive skeleton gain and the orientation gain at the longer
estimation windows.

\subsection{What orientation contributes}
\label{sec:orientation-role}

The edge orientations contribute robustness to the choice of estimation
window rather than a higher level of performance. The skeleton-only
allocator is sensitive to the window ($0.372$--$0.403$ across the 4
windows, and below the baseline at 189 days). However, \semcovhrp{}
($0.395$--$0.415$) and \toposemcovhrp{} ($0.399$--$0.419$) perform well
across all windows (see Figure~\ref{fig:nav} for the 252-day NAV paths).
The U shape in Figure~\ref{fig:gradient} demonstrates when orientation
pays, that is, when the sample moments feeding the allocator are the
least reliable. At 189 days the sample covariance is estimated from
barely $1.9$ observations per asset (noise). At 504 days, however, it
averages across regimes that it should distinguish (staleness). At the
252-day window, which the estimation literature positions at the optimum
between noise and staleness, and at which the skeleton's own
contribution is highest, orientation adds least. $\Sigma_{\mathrm{SEM}}$
is based on the contemporaneous graph and its shock variances, so it
substitutes structure for sample-moment quality at each end of this
trade-off. On this reading, the SEM covariance is a regulariser of the
allocation step rather than a means of generating additional return. The
controls at the end of this subsection determine which of its properties
does the regularising, and the answer is not direction. There are two
qualifications to this reading. First, the window moves the graph and
the sample moments in tandem (both are estimated on the same window), so
the gradient cannot by itself separate the degradation of the moments
from the degradation of the graph. The consistency of the discovered
graphs across windows (density $6.3$--$6.9\%$ at every window;
Section~\ref{sec:asset-graph}) supports the reading that the moments
deteriorate faster. Second, the 189-day arm of the U relies on the
choice of skeleton control (Section~\ref{sec:decomposition}), so I claim
the regulariser mechanism for the long-window arm only. Third, the
504-day arm is measured on a series whose first 12 months are equal
weight for both allocators (Section~\ref{sec:method}), so its contrast
is diluted towards zero rather than inflated.

There is an alternative explanation, and I test it directly. The
contrast $\semcovhrp{}-\skelhrp{}$ compares the DAG's implied covariance
against the sample covariance at the allocation step. However, the
implied covariance has two properties that are unrelated to the
direction of the edges and could drive a performance gain by themselves.
First, it is a structured estimator with far fewer effective parameters
than the sample covariance, so it behaves like a shrinkage estimator.
Second, its independent-shock assumption removes the common market
factor. Either of these properties can be realised without a graph at
all. I test whether either of them is responsible for the performance
gain, and I noted what each possible outcome would mean before executing
either test (Section~\ref{sec:believe}). Both controls keep \skelhrp{}'s
clustering and replace its sample covariance at the allocation step. The
first control uses a Ledoit--Wolf shrunk covariance
\cite{ledoitwolf2004}. The second uses a de-factored covariance: each
asset is regressed on the window's equal-weight market return, and
allocation relies on the covariance of the residuals. Neither control
sees an edge direction.

I find that shrinkage does not reproduce the gain. The Ledoit--Wolf
control sits below \skelhrp{} in every window ($\rsDlwSharpeWone$,
$\rsDlwSharpe$, $\rsDlwSharpeWthree$, $\rsDlwSharpeWfive$ across the 4
windows), and \semcovhrp{} beats it by $+0.018$ to $+0.042$ ($p=0.05$ at
504 days, its strongest window; $p \geq 0.08$ elsewhere). In contrast,
de-factoring does reproduce the gain. The de-factored control
($\rsDdfSharpeWone$, $\rsDdfSharpe$, $\rsDdfSharpeWthree$,
$\rsDdfSharpeWfive$) matches \semcovhrp{} in every window, leaving a
residual of \semcovhrp{} minus control between $-0.011$ and $+0.004$ ($p
\geq 0.5$ throughout). This indicates that the gain from the implied
covariance is attributable to its assumption of independent shocks,
which eliminates the common market factor, rather than to the edge
directions themselves. This is the interpretation I wrote down in
advance for this outcome. What remains for the edge orientations is a
weaker, conditional role. DYNOTEARS' edge magnitudes recover the full
de-factoring benefit and do not diminish it. The same construction on
VARLiNGAM graphs, which are similarly structured and similarly
de-factored, yields nothing, and the ridge-Granger version, with its
degraded magnitudes, collapses (both are shown in the discovery-method
comparison of the next subsection). This means that trustworthy edge
magnitudes are necessary for the construction to work, but the working
ingredient is the de-factoring rather than the direction of the edges.

The skeleton deserves the same treatment, so I apply the same scepticism
to its gain. Its gain over \corrhrp{} ($+0.022$ at 252 days) could in
principle be achieved by any sparse conditional-dependence structure of
the same density, with no discovery at all. A third control tests this
directly, and as before I wrote down what each outcome would mean before
executing it (\texttt{PREDICTIONS\_SKELETON\_CONTROL.md}). This control
is \skelhrp{} with the discovered skeleton replaced by a thresholded
partial-correlation matrix. I invert a Ledoit--Wolf covariance to obtain
a precision matrix, keep the largest-magnitude cells, and match the
density to the paired graph's nonzero-cell count. The graph enters only
through that scalar. I find that the graph-free skeleton fails to
reproduce the gain at the window where the gain peaks, and reproduces it
elsewhere. At 252 days it earns $\rsDpcSharpe$ while the discovered
skeleton earns $0.403$, a residual of $+0.025$ ($p=0.008$), and its own
gain over the correlation baseline is zero there ($-0.003$, $p=0.86$).
At the remaining 3 windows the two skeletons are statistically
indistinguishable (residuals within $\pm 0.004$, $p \geq 0.69$). This
includes the 378-day window, where the skeleton's gain ($+0.018$) is
four fifths of its peak and the graph-free skeleton matches it in full
($+0.021$ over the baseline, $p=0.21$). The outcome sits between two of
the readings I wrote down in advance. One window is significantly
positive, which the pre-committed reading of a discovered-skeleton
dividend requires, but that reading also required no negative-signed
window, and the 378-day residual is $-0.003$. I therefore apply that
reading to the 252-day window only: the gain made by the skeleton at 252
days is attained by the discovered skeleton itself, while at 378 days a
partial-correlation skeleton of the same density does as well.
The mechanism story is therefore asymmetric in an informative way. The
gain made by the orientations at the allocation step requires no graph,
because de-factoring reproduces it. The gain made by the skeleton at 252
days does require the graph.

\subsection{Robustness to design parameters}

The first design parameter is the sparsity threshold $\tau$.
Thresholding the graph at $\tau\in\{0,0.01,0.05,0.10\}$ leaves the
treatment flat or slightly improving (\topohrp{}, the allocator that
uses the DAG's topological order at the ordering step: $0.399\to0.402$
at the heaviest threshold), while the skeleton control drifts down
($0.403\to0.394$; Table~\ref{tab:tau}). The structural risk-parity
allocator, which I also swept, moves the same way ($0.398\to0.407$).
This indicates that the two orientation-aware allocators I swept are not
artefacts of the regularisation threshold; \semcovhrp{} and
\toposemcovhrp{} were not swept. These sweep differences are point
estimates; I did not formally test them.

The second is transaction costs and turnover. The gain from the implied
covariance at the allocation step is not sensitive to the level of
transaction costs, at least in point estimates.
\semcovhrp{}$-$\skelhrp{} at 504 days moves from $+0.022$ to $+0.025$ as
costs rise from 0 to 20\,bps (differences on unrounded series;
Table~\ref{tab:cost}). This is because \semcovhrp{}'s turnover ($0.102$
one-way per rebalance) is less than the control's ($0.112$). The
statement does not extend to the ordering step at short windows.
\toposemcovhrp{} has the highest turnover in the family ($0.140$), and
its 252-day gain decreases from $+0.004$ at zero cost to $0.000$ at
20\,bps, while its 504-day gain remains intact through the sweep. In
short, the implied covariance does not win by trading less and is not
eroded by trading more, whereas the topological ordering at 252 days is.

The third is the discovery method. Under VARLiNGAM graphs the
orientation effect is absent at all 4 windows (4 of 12 contrasts
positive, mean $-0.005$; Figure~\ref{fig:forest}, right, and the grey
series of Figure~\ref{fig:gradient}). Therefore, the decomposition is
contingent on the discovery method. DYNOTEARS' jointly optimised,
acyclicity-constrained $W$ supports orientation-aware allocation, while
VARLiNGAM's ICA-ordered $B_0$ does not. This is in line with VARLiNGAM's
identification weakening with longer windows, as the residuals become
more Gaussian. At the 189-day window it is also in line with its
unpruned $B_0$ saturating in the thin-sample regime (density $32\%$
against DYNOTEARS' stable $6$--$7\%$; Section~\ref{sec:asset-graph}), so
its short-window graphs carry little usable orientation signal either.

A DYNOTEARS graph supplies two pieces of information at once, the
direction of each edge and a fitted magnitude for it, so its cells alone
cannot show which of the two the orientation effect uses. The
ridge-Granger control distinguishes these two: it preserves a usable
ordering while degrading the magnitudes. On its graphs, causal-ordered
bisection survives (\topohrp{} $=0.393$ against DYNOTEARS' $0.399$),
whereas the allocator that relies on the implied covariance collapses
(\semcovhrp{} $=0.352$; a gap of $-0.060$, $p=0.11$). A ridge-VAR
coefficient matrix preserves a usable ordering but not structural effect
sizes. This shows that the orientations' contribution does not hinge on
merely knowing which way the arrows point (an ordering survives even a
one-lag ridge regression). It hinges on edge magnitudes that are
reliable enough to propagate shocks, which only the jointly optimised
DYNOTEARS fit provides. This clarifies the answer to the research
question rather than adding another benchmark: ``orientation'' pays
through its weighted, propagatable form.

The last check uses a second member of the hierarchical family, HERC.
Chapter~\ref{chap:background} argued that the limitation is family-wide:
any hierarchical allocator that clusters on a symmetric matrix loses
orientation, regardless of the rule that defines how the tree is read.
Whether the measured decomposition generalises to different rules for
reading the tree is a distinct, empirical question. I test this on a
second member, and, prior to running any cell, I noted what each of the
possible outcomes would imply (\texttt{PREDICTIONS\_HERC.md}). The
member is a full-recursion Hierarchical Equal Risk Contribution
allocator \cite{raffinot2018herc}. It has the same clustering step and
cluster-risk measure as the HRP family; however, instead of bisecting
the leaf ordering, it descends the actual topology of the dendrogram. I
find that the outcome is mixed. The sign of the orientation contribution
carries at every window, the sign of the skeleton contribution does not,
and the whole HERC family lies well below its HRP counterparts (cells
and contrasts in Appendix~\ref{app:tables}). As such, the size of the
decomposition depends on the allocator. What generalises to this second
member is the sign of the orientations' contribution. Therefore, I
retain only the structural part of the family-wide claim: every member
of the family loses orientation at the clustering step, but the size of
the resulting performance gain depends on the member. All 12 HERC cells
are included in the \rsNtrials\ configurations and belong to neither SPA
family.

\subsection{Regime dependence}
\label{sec:regimes}

The prior-verification result (Section~\ref{sec:discovery-run})
showed that the directional prior changed the fitted graph most in the
2008 and 2022 stress windows. This motivated the hypothesis that
orientation-aware allocation would be most
valuable in crises. The regime-conditional analysis contradicts this. At
the 252-day window, the edge of the orientation-aware allocators over
the \corrhrp{} baseline concentrates in the bottom VIX quintile
($+0.29$/$+0.31$ Sharpe for \semcovhrp{}/\toposemcovhrp{}) and is
slightly negative in the top quintile. In NBER recessions, the
skeleton-only allocator is the strongest (Figure~\ref{fig:regime} and
Table~\ref{tab:regime-full}, Appendix~\ref{app:tables}). These figures
are purely descriptive. I ran no formal regime-level test, and
conditional Sharpe levels are mechanically inflated in the calm regime,
so only within-regime differences should be read. One plausible reading
is that in stress, correlations rise towards one and any structure is
overwhelmed by the common factor, while in calm markets cross-sectional
causal heterogeneity is the signal. Whatever the mechanism, the
hypothesis as stated was wrong. Howard et al. had anticipated this
outcome, with their finding that their centrality alpha resides in
stable regimes (Section~\ref{sec:howard-theme}).

The first correction addresses non-normality and selection bias through
the Probabilistic and Deflated Sharpe ratios. The Probabilistic Sharpe
ratio of each headline allocator, the probability that its true Sharpe
exceeds zero given the sample's higher moments, is high (\corrhrp{}
$\rsCorrPSR$, \skelhrp{} $\rsVprimePSR$, \semcovhrp{} $\rsDonePSR$ at
252 days). This suggests that the levels are not artefacts of fat tails.
To account for selection, I next deflate against the best Sharpe
expected from \rsNtrials\ no-skill trials. The highest Deflated Sharpe
ratio in the study is observed for \toposemcovhrp{} at the 378-day
window ($\rsDtwosDSRWthree$). This is followed by the direction-free
de-factored control ($\rsDdfDSRWthree$) and \semcovhrp{}

mimics them, and two \undirhrp{} cells, which is consistent with the
mechanism finding of Section~\ref{sec:orientation-role}. Since every
configuration is deflated against the same trial count over the same
calendar, the DSR here is close to a monotone transform of the Sharpe
ratio, so the ordering of the decomposition survives deflation by
construction. The informative content of the DSR is its level. The SPA
tests below assess how much statistical separation survives.

The second correction is for comparisons over a family of allocators.
Hansen's SPA test adjusts for the search over such a family. Its null
hypothesis is that no allocator in the family performs better than the
baseline, and the test takes into account the fact that the most
appealing member was chosen from the family. I apply the test to two
families: (i) the causal allocators against the \corrhrp{} baseline, and
(ii) the orientation-aware allocators against the DYNOTEARS skeleton
control \skelhrp{} (Section~\ref{sec:decomposition}). In both families
the candidates are drawn from both discovery methods, so family (ii)
also puts the VARLiNGAM orientation-aware cells against the DYNOTEARS
skeleton. I conduct each test twice at each window. The first run is
over the full grid of 7 allocators from the experiment plan: all 7 in
family (i), and the 5 orientation-aware members in family (ii). The
second is over a narrowed grid of 5 allocators, consisting of the 4
allocators that cover the 2 entry points of information from the DAG
into HRP (Table~\ref{tab:crossing}) plus the second symmetrisation
control, \undirhrp{}. In family (ii) the narrowed grid leaves the 3
orientation-aware allocators of Table~\ref{tab:crossing}. I fixed the
narrowing only
after I had the results of the 4 windows, so the full family's numbers
are the primary ones and the narrowed family's follow and are labelled
as such. Table~\ref{tab:spa} contains the $p$-values. Its last column
combines all 4 windows into a single test against the 252-day baseline,
therefore correcting for the search over windows as well as the search

uncertainty stated. The point estimates for the decomposition are clear
and internally consistent. There is a stable total gain whose
composition depends on the estimation window: the skeleton's
contribution is hump-shaped and peaks at 252 days, and the orientations'
contribution is positive at every window and largest at the two

components. The orientations' gain at the allocation step is reproduced
by a graph-free de-factored covariance, so it is robustness rather than
directional information as such. The skeleton's 252-day gain is not
reproduced by a graph-free skeleton of matched density, so the gain at
the conventional window does need the discovered graph. The largest
defensible claim is modest. Substituting a DYNOTEARS graph for the
correlation matrix pays through the skeleton near the 1-year window, and
keeping the orientations imposes no cost while improving robustness to
the choice of estimation window. The evidence does not support
attributing the allocation-step gain to edge direction, any orientation
effect under VARLiNGAM graphs, or the stress hypothesis. In a nutshell,
the point estimates are precise and consistent in sign, their
significance holds only under the post-hoc narrowed family, and a
direction-free control replicates the primary mechanism.

\section{Caveats}
\label{sec:believe}

There are several things that could potentially undermine the validity of this project.

The first threat is low power: the effect sizes are smaller than the minimum detectable effect. 
The difference in Sharpe ratio I observe is around $0.01$--$0.03$ over 18 years. 
The corresponding block bootstrap standard errors at the 252-day window are $\rsContrastSETotal$ for the total contrast (\semcovhrp{}$-$\corrhrp{}), and $\rsContrastSEOrient$ for the orientation contrast (\toposemcovhrp{}$-$\skelhrp{}).
The small effect sizes relative to the standard errors indicate the study's lack of power.
At $5\%$ size and $80\%$ power, the one-sided minimum detectable effects
are ${\approx}\,\rsContrastMDETotal$ and
${\approx}\,\rsContrastMDEOrient$ net Sharpe respectively. 
These minimum detectable effects are much larger than the observed $+0.031$ total gain and the largest orientation gain of $+0.023$ (at the 504-day window). 
By the same token, the null hypothesis rejections that do occur are marginal.
Pairwise comparisons of 12 orientation differences yield one $p=0.048$, which is approximately what multiplicity would predict under the null hypothesis anyway.
Rather than significance testing across different contrasts to establish an orientation effect, therefore, the main evidence for the existence of an orientation effect is the fact that there is a consistent positive contribution across windows and
treatments (Section~\ref{sec:decomposition}).

The second threat is that some of the design choices of my research were influenced by earlier results I had obtained.
The research question itself was informed by initial research I conducted which used Hierarchical Sensitivity Parity \cite{rodriguez2023hsp}
(Section~\ref{sec:hrp-theme}) as a baseline, replacing its correlation-based driver selection with selection from the discovered graph.
I correct for this in the Deflated Sharpe ratio: 
\rsNtrialsPhaseI\ of the \rsNtrials\ total configurations corrected for were from this initial research phase, with the remainder being configurations from the primary arm of the research project.
Appendix~\ref{app:hsp} reports the two null results from the initial HSP research.
The estimation windows themselves were also changed over time. I first used the conventional 252- and 504-day windows. These results indicated a temporal shift in the marginal contributions of the skeleton and the edge orientations; to analyse this further, I added in the 189- and 378-day windows.
However, the risk from these post-hoc changes is low. 
I ran causal discovery and allocation over the added windows identically to the initial windows.
Also, the total number of configurations, \rsNtrials, accounts for both the initial and subsequent (primary) research directions, across all phases and windows, which means that the multiplicity-aware tests account for the change in direction.
The final influenced design choice is the family of allocators tested for.
The initial plan was to use a family of 7 allocators, and this is indeed the main family I discuss in the report. However, after seeing the results, I narrowed it to the 5 allocators that are discussed in Chapter~\ref{chap:sensitivity}. The reason for doing so was to focus only on the allocators where the causal graph enters into HRP's two entry points; the two excluded allocators take in the graph elsewhere. Both are orientation-aware allocators, with
one replacing the hierarchy with risk parity over structural shocks, and the
other constructing the clustering distance from shared upstream
ancestry. However, the timing (restricting the family after having seen the overall results) means the null hypothesis rejections from testing the restricted family can only be suggestive, not definitive.
Both families' SPA $p$-values are recorded in Table~\ref{tab:spa}. 
The null is never rejected for the full (7-allocator) family, while three of the ten narrowed-family tests have rejections.
The results from the 2 allocators that were excluded from the narrowed family are directionally consistent with the rest of the allocators: they outperform the baseline in all 16 of their cells, across both discovery methods and all 4 windows, by $+0.002$ to $+0.024$. This lends credence to the fact that I did not cherry-pick allocators that had negative performance.
Separately, I realised a potential objection lay in the notion that $\Sigma_{\mathrm{SEM}}$'s gain might be unrelated to causal direction, given that it also acts like shrinkage and assumes independent shocks and so de-factors assets. I therefore added the two mechanism controls discussed in Section~\ref{sec:orientation-role}.
However, I pre-recorded their interpretations and count them among the \rsNtrials\ configurations.

The third threat is scope: a single asset class, one universe and an
approximated index. Everything here concerns long-only allocation within
${\sim}100$ US large-caps, and every variant absorbs the full
${\approx}50\%$ GFC drawdown. Whether the decomposition transfers to
universes with richer exogenous structure (multi-asset, credit,
commodities) is untested. The top-by-market-cap approximation of the
S\&P 100, the fixed snapshot-union universe (whose membership is
partially determined by market caps realised later in the sample), and
the absence of delisting returns (Section~\ref{sec:data}) carry mild
residual survivorship and look-ahead effects. Their sign is favourable,
but every allocator on the same panel shares them, so they raise the
absolute levels rather than the pairwise contrasts that are of interest
in this thesis. Quantifying them with a point-in-time universe is left
to future work.

The fourth threat concerns the identification of edge orientations. DYNOTEARS
does so through its score and the acyclicity
constraint; Section~\ref{sec:cd-tools} discusses the fact that, on unscaled data, this score
orients edges by marginal variance. I eliminate this effect by fitting on
standardised data. However, even after scaling, ordering by explained variance persists \cite{reisach2023r2}. For assets, explained variance is primarily due to market exposure, which implies that some portion of the discovered edge orientations may be based on how much market exposure each asset has, rather than a true causal ordering.
I did not assess this threat, but its magnitude could be calculated by estimating the fraction of edges that point from lower- to higher-$R^2$ assets. Another method would be to just use an ordering by $R^2$ alone (rather than using a graphical ordering. This would represent a control for \topohrp{} in the same way that the partial-correlation
network controls for \skelhrp{}. 
In any case, as all the allocators receive the same graph, the performance decomposition is unaffected.

One other caveat is the fact that my results are method-dependent, as the performance gain from edge orientations only exists under DYNOTEARS graphs. I therefore can only claim that 
DYNOTEARS' contemporaneous structure supports orientation-aware allocation, rather than a broader claim about causal edge orientations being useful for portfolio allocation in general.

\chapter{Conclusions and Future Work}
\label{chap:conclusion}

\section{Summary of findings}
\label{sec:summary}

This thesis asked a single question: when the correlation matrix in
hierarchical portfolio allocation is replaced by a causal graph, does
performance improve, and what part of any improvement is attributable to
the graph's skeleton versus its edge orientations? To make the question
answerable, I built the machinery it presupposes. The first component is
a reproducible rolling discovery pipeline that delivers the same
asset-to-asset DAG to each allocator (Chapter~\ref{chap:discovery}). The
second is a family of orientation-aware allocators, with skeleton and
correlation controls verified orientation-blind under stated invariances
(Chapter~\ref{chap:sensitivity}). This fulfils the second premise of
Section~\ref{sec:question}. I then answered the question under inference
that accounts for multiplicity, non-normality and stability
(Chapter~\ref{chap:evaluation}).

In sum, replacing the correlation matrix with a causal graph yields a
consistent performance improvement across estimation windows, but the
component of the graph responsible for that improvement is sensitive to
the choice of window. Against the primary skeleton control, the skeleton
pays off most clearly near the conventional 1-year window, while the
edge orientations pay off at every window and, irrespective of the
orientation-blind control, from 1 year out. The differences between
windows are of the order of one standard error, and I widened the window
grid midway through the analysis, so the shapes carry that uncertainty.
The edge orientations buy robustness to the estimation window, as
opposed to improved performance. A direction-free de-factored covariance
obtains the same robustness, hence the mechanism is market-factor
removal rather than directional content. Using Hansen's SPA test to
correct for the search over allocators, I find that the results are
insignificant over the full family of 7 allocators at every window. They
reach conventional significance only over the narrowed family of 5, at
the longest estimation windows, marginally, where the point estimates
also peak. In detail (net annualised Sharpe, 2007--2024, monthly
rebalancing, 5\,bps costs, windows of 189/252/378/504 trading days):

\begin{enumerate}[itemsep=2pt]
  \item The total gain is consistent across estimation windows. Using
        the DYNOTEARS graph instead of the correlation matrix is worth
        $+0.018$ to $+0.032$ net Sharpe (\semcovhrp{} $-$ \corrhrp{}) at
        every window. 19 of the 20 DYNOTEARS comparisons against
        \corrhrp{}, and 17 of the 20 VARLiNGAM comparisons, are
        positive.
  \item Its composition shifts with the window. The skeleton's
        contribution is hump-shaped and reaches its maximum at 252 days.
        The edge orientations' contribution is always positive and
        U-shaped, and is most pronounced where the sample moments are
        weakest. The orientations build robustness to the estimation
        window rather than level, and at the 378-day window
        \toposemcovhrp{} (the allocator that uses both the DAG's
        topological order and its implied covariance) has the highest
        Deflated Sharpe ratio of all \rsNtrials\  configurations
        evaluated ($\rsDtwosDSRWthree$).
  \item The orientation mechanism operates without a graph, but the
        skeleton requires one. A de-factored covariance without a graph
        yields the gain of the implied covariance at the allocation step
        at every window, demonstrating that the robustness of the
        orientations is accomplished by the removal of the market
        factor. The matching graph-free skeleton control is unable to
        reproduce the skeleton's 252-day gain, so the component that
        pays off at the conventional window does require the discovered
        graph (Section~\ref{sec:orientation-role}). The shapes
        themselves depend on the choice of skeleton control at 189 days
        (limitation (vii) below).
  \item Significance depends on the family of allocators being tested. I
        run Hansen's SPA test, whose null hypothesis is that no
        allocator in the family outperforms the baseline, over both the
        full grid of allocators from the experiment plan and the
        narrowed grid fixed after the results were seen (7 and 5
        allocators against the correlation baseline, 5 and 3
        orientation-aware allocators against the skeleton control). For
        the full grid, there is no rejection of the null at any window.
        For the narrowed grid, there are marginal rejections at the
        longest estimation windows only. With the 4 windows combined into a single test, there is
        no rejection for either family (Table~\ref{tab:spa}). The $90\%$
        Model Confidence Set fails to distinguish treatments from
        controls.
  \item The effect is method- and allocator-specific. Under VARLiNGAM
        graphs the orientations add nothing at any window (limitation
        (ii)). Under the ridge-Granger control, which degrades the edge
        magnitudes, the topological ordering remains but the implied
        covariance fails, so the value is tied to reliable edge
        magnitudes. On a second family member (HERC), only the sign of
        the orientations' contribution generalises
        (Section~\ref{sec:decomposition}). Descriptively, the edge
        appears in calm regimes, and the stress hypothesis is rejected.
\end{enumerate}

\section{Contributions}
\label{sec:contributions}

The contribution of this thesis is the orientation-aware allocator
family and the fixed-graph ablation design. The decomposition of
Chapter~\ref{chap:evaluation} is what that instrument found. This one
claim unpacks into a methodological core and two strands that stem from
it:

\begin{itemize}[itemsep=2pt]
  \item The methodological core is the orientation-aware allocator
        family: allocation on the SEM-implied covariance, which is
        de-standardised and calibrated on the fit window's residuals,
        and causal-ordered bisection, which replaces the clustering
        dendrogram with the DAG's topological order. I complemented this
        with the fixed-graph ablation design, which makes the skeleton
        and the orientations separately measurable, with controls
        verified orientation-blind under stated invariances. To the best
        of my knowledge, both the family and the decomposition are
        novel. The closest prior work \cite{howard2025causal} never sets
        weights from its graphs.
  \item The empirical strand is what that instrument found. I traced the
        decomposition over 4 estimation windows and found that the total
        is stable. Against the primary skeleton control, the
        contribution of the skeleton is hump-shaped with a peak at 252
        days, and the contribution of the orientations is positive at
        every window (and positive under both skeleton controls from 1
        year out). After adjusting for the search over allocators, the
        results are insignificant over the whole family and marginally
        significant only at the longest windows over the narrowed
        family. I identified the mechanism behind the allocation-step
        gain as market-factor removal by a direct control, and I
        characterised the dependence of the decomposition on discovery
        method and regime.
  \item The meta-scientific strand is the pipeline itself. I constructed
        a fully deterministic and reproducible pipeline. In the process,
        I identified and resolved a data-determinism defect, and the fix
        overturned two previously drawn conclusions. Each design
        extension is stated as such, each cell is cache-verified, and
        the harness is gated on an exact replication of the prior
        phase's result.
\end{itemize}

\section{Limitations}
\label{sec:limitations}

(i) The components of the decomposition are $0.01$--$0.03$ Sharpe. This
is close to the 18-year detection floor, individually insignificant
against the stronger controls, and quantifiably underpowered. The
one-sided minimum detectable effects at $80\%$ power are
${\approx}\,\rsContrastMDETotal$ (total) and
${\approx}\,\rsContrastMDEOrient$ (orientation) net Sharpe, roughly
twice the observed gains (Section~\ref{sec:believe}). The point
estimates are exactly reproducible. The inference, where it is
significant after correcting for the search over allocators, is
marginal, is significant only over the post-hoc narrowed family and not
over the full family, and is not significant once the search over
windows is corrected for as well. (ii) The orientation effect is present
under one discovery method (DYNOTEARS) only. Until another method
reproduces it, it should be treated as a property of DYNOTEARS'
contemporaneous structure rather than of markets. The de-factored
control shows that the orientations' allocation-step gain can be
achieved without any graph, whereas the matching control shows that the
skeleton's 252-day gain cannot. (iii) The study covers long-only US
large-cap equity only. Every variant absorbs the full ${\approx}50\%$
GFC drawdown, and transfer to richer universes is untested. (iv) The
universe approximates the S\&P 100 by market-cap ranking and a fixed
snapshot union, with mild residual survivorship effects. (v) The
asset-block SEM marginalises over the macro drivers, so the assumed
independence of the structural shocks is an approximation. (vi) Three
design choices were based on earlier results. The choice of research
question was informed by the results of the first phase (the
Hierarchical Sensitivity Parity route, \rsNtrialsPhaseI\ of the
\rsNtrials\ configurations). The window grid was widened to 4 estimation
windows partway through the study. And the family tested by SPA was
narrowed from the full 7 allocators to 5 after the results were obtained
(Section~\ref{sec:believe}). All three are stated, both families'
numbers are reported, and the Deflated Sharpe ratio corrects for all
\rsNtrials\ configurations the search ever touched. However, a deflation
correction is not a substitute for out-of-sample replication. The
2025--26 slice (Section~\ref{sec:oos}), whose protocol was fixed before
the data existed, provides the directional part of that replication:
every sign I predicted came out as predicted. At 19 months it can
certify signs and nothing more, so the significance question remains
open. (vii) At the shortest window the two orientation-blind controls
themselves disagree (\undirhrp{} $-$ \skelhrp{} $= +0.025$, $p=0.013$),
so the 189-day contributions carry extra estimator uncertainty. More
generally, the hump and U shapes of the decomposition are measured
against \skelhrp{}. Against \undirhrp{}, the skeleton contribution is
flat and the 189-day orientation contribution is slightly negative
(Section~\ref{sec:decomposition}). (viii) I have not measured the
month-to-month persistence of the discovered edges. The stability of the
graph over time is supported by the determinism of the fits and the
stability of aggregate diagnostics, rather than by an edge-overlap
measure.

\section{Broader impact}
\label{sec:impact}

For investors, the relevance is that allocation research is used by
asset managers and pension schemes, so its failures are borne, diffusely
and years later, by end savers. The characteristic harm in this
literature is a convincing backtest of an overfit strategy, rather than
a malfunctioning system. Evaluation that corrects for the search over
configurations is therefore how research method protects investors, and
I apply it to this report's own headline. The same discipline deals with
what might be called causal-washing. A ``causal'' label invites a
greater degree of trust than is warranted, and the finding here is that
the value of a causal method can be modest, window- and
method-dependent, and, at the conventional 1-year window, largely due to
structure that cheap symmetrisation already captures. The label
guarantees nothing; the decomposition holds the information.

For the field, one of this project's technical choices generalises into
a norm. The determinism episode of Section~\ref{sec:cache}, in which a
reproducibility fix overturned two conclusions, argues that
reproducibility should be a prerequisite of publication rather than an
aspiration. The deterministic, seed-free construction of the allocator
family is the design corollary, and it is what ensures that each number
in this report is exactly replicable.

There is also a cost dimension. The content-keyed cache reduced the
marginal cost of a configuration from ${\sim}15$ hours to ${\sim}40$
seconds. That is what made a \rsNtrials-configuration study, and hence
its multiplicity correction, affordable at all. The compute and energy
economics of caching-first experimental design are a transferable, if
unglamorous, contribution to sustainable empirical research. Here,
rigour and efficiency went hand in hand.

\section{Future work}
\label{sec:future}

(1) The first extension is a second orientation source, since of the
caveats to the decomposition, method-dependence is the dominant one.
Repeating the fixed-graph ablation on graphs from a different family
would test whether orientation value is a DYNOTEARS artefact. The
non-linear NTS-NOTEARS is the natural candidate. In a reduced-scope
probe, I confirmed that the directional prior transfers to it, but its
${\sim}10\times$ fit cost postponed a full backtest. (2) The second is
signed structural allocation. Equalising risk contributions over
structural shock origins (where risk enters the causal system), as
opposed to over correlated returns, is the natural next use of
$\Sigma_{\mathrm{SEM}}$. A long-only version was among the 7 allocators
of the pre-registered grid and is included in the full-family SPA tests
of Section~\ref{sec:believe-rigour}. However, exact per-shock parity
generally requires shorting, which places it in a long--short mandate
rather than the long-only setting studied here. (3) The third is richer
universes. Cross-asset causal chains are plausibly longer-lived than
those among 99 co-moving large-caps, so multi-asset-class portfolios are
where the skeleton/orientation split could differ materially. (4) The
fourth is orientation-aware risk attribution. The total-effect matrix
$B$ facilitates ex-post decompositions that attribute a month's loss to
the shocks that caused it, which is beyond what the correlation toolkit
can express. This is of value even where the allocation gain is modest.
The infrastructure built in this project (the deterministic pipeline,
the discovery cache and the ablation harness) makes each of these a
matter of days rather than months of compute. As this project discovered
twice, that is a prerequisite for trusting the answers.

\section{The first phase: the driver route and its two null results}
\label{app:hsp}

The project's first phase built on Hierarchical Sensitivity Parity (HSP;
Section~\ref{sec:hrp-theme}). It asked whether replacing HSP's
correlation-based driver selection with selection from a discovered
causal graph improves the allocation. I evaluated three configurations
on the panel and protocol of Chapter~\ref{chap:evaluation}. The first is
HSP as published: correlation-selected drivers, neural sensitivities,
and HRP on the sensitivity distance. The second is a causal-selection
variant that chooses the $K{=}17$ drivers based on their aggregate
outgoing influence in the DYNOTEARS graph (also run under VARLiNGAM).
The third is a closed-loop variant that feeds each month's realised
excess Sharpe over equal weight back into the driver scores, through an
exponentially weighted utility with blend weight $\alpha$ and decay
$\gamma$. Over the 252- and 504-day windows, a sweep over
$K\in\{10,14,17,20,25\}$ and a $3\times3$ grid over $(\alpha,\gamma)$,
the phase accounts for \rsNtrialsPhaseI\ of the \rsNtrials\
configurations that the Deflated Sharpe ratio corrects for. Two of them
are the skeleton cells targeted by the replication gate of
Section~\ref{sec:ablation-design}. The remaining \rsNtrialsPhaseII\ of
the \rsNtrials\ configurations are the graph-route cells of this
study. Both of the phase's results were null.

The claimed improvement is contained within the method's own noise. At
the 252-day window and $K{=}17$, causal selection outperforms HSP as
published by $+0.010$ net Sharpe ($p=0.27$). The sign reverses at
$K=10$, $20$ and $25$ ($-0.015$, $-0.016$, $-0.010$), and no difference
at any $K$ is significant ($p=0.10$--$0.77$). As a sensitivity test, I
re-ran the same causal-selection configuration under \rsSeedN\ network
seeds, with discovery cached so that the network initialisation was the
only varying ingredient. Its net Sharpe varies across $[\rsSeedMin,
\rsSeedMax]$ (median $\rsSeedMedian$; Figure~\ref{fig:seed}). The seed
range ($\rsSeedRange$) is more than double the $+0.010$ edge, and the
committed seed sits at the $\rsSeedPct$th percentile of its own
distribution, meaning that at the least favourable seed the edge almost
completely disappears. In addition, plain correlation-distance HRP
(\corrhrp{}) outperforms HSP as published at the same window
($\rsCorrSharpe$ against $0.371$), indicating that the
driver-and-network machinery subtracts value relative to textbook HRP.
The $90\%$ Model Confidence Set over the \rsMcsUniverse\ distinct
252-day strategies of Section~\ref{sec:believe-rigour} retains
\rsMcsSize\ of them and eliminates only HSP as published. All
graph-route allocators of Chapter~\ref{chap:sensitivity} are
deterministic, and at the 252-day window each is above the maximum of
the seed distribution.

\begin{figure}[tbp]
  \centering
  \includegraphics[width=0.85\textwidth]{figures/phase_ii_seed.png}
  \caption{The seed audit: net Sharpe of the causal-selection HSP variant across \rsSeedN\ network seeds at the 252-day window.}
  \label{fig:seed}
  \floatnote{Dotted line: HSP as published. The seed range exceeds the variant's claimed edge over its baseline, and every graph-route allocator shown sits above the seed distribution's maximum.}

The monthly feedback loop cannot learn. Across the full
$\alpha\in\{0.4,0.6,0.8\}\times\gamma\in\{0.1,0.3,0.5\}$ grid, the
closed loop's weights are equal to the open-loop variant's at every
rebalance. This is because the utility blend is only able to re-rank the
drivers within the causally selected set. Even where it has the
opportunity to act, its signal is too weak to act on. The monthly reward
is a Sharpe ratio estimated from 21 daily observations, with a sampling
standard error of approximately $\rsSharpeSE$. Across 215 rebalances it
has mean $\rsRewardMean$ and standard deviation $\rsRewardStd$, a
per-update signal-to-noise ratio of approximately $\rsRewardSNR$. A
feedback rule at this frequency receives one number a month that is
almost entirely noise, so no learning rule could extract the signal
without lengthening the reward window or raising the update frequency.

\section{Hyperparameters}

For reproducibility, the settings used were as follows. Discovery: DYNOTEARS lag $p=1$,
$\lambda_W=\lambda_A=0.05$, fit-time edge threshold $0.01$ (the
extraction threshold $\tau$ of Section~\ref{sec:asset-graph} defaults to
$0$ on top of this); VARLiNGAM with lingam pruning disabled (adaptive
lasso fails at $d>n$); ridge-Granger ridge $\lambda=10^{-2}$ scaled by
window length, density-matched per window to the paired DYNOTEARS graph.
Allocators: single-linkage where clustering is used;
$\Sigma_{\mathrm{SEM}}$ with diagonal shock variances from fit-window
residuals, nearest-PSD projection and ridge load
$10^{-6}\operatorname{tr}(\Sigma)/N$; topological tie-break by total
downstream influence then name. Protocol: 5\,bps one-way (swept
$\{0,5,10,20\}$); windows 189/252/378/504 trading days; holding and step
21 trading days; 215 (189- and 252-day windows) / 209 (378-day) / 203
(504-day) rebalances, 2007-01--2024-11 (rebalances before a window's
burn-in completes fall back to equal weight, identically for every
allocator at that window); Politis--Romano bootstrap, 10{,}000
resamples, mean block 21 trading days.

\section{Reproducibility}

All results are derived from committed code and cached data and are
exactly reproducible. Following the data-determinism fix of
Section~\ref{sec:cache}, two independent end-to-end runs generate the
same graphs, weights and NAVs. The replication gate confirms this:
\skelhrp{} against the prior phase's committed bundle results in
$\Delta$Sharpe $= 0$ and a maximum weight difference of $0.0$ across all
215 rebalances, and I re-verified it on the 4-window grid by an exact
repeat of a 378-day cell. The ablation was executed on 1{,}684
cache-verified graph fits with a 100\% hit rate, and each backtest
regenerates from the cache in ${\approx}40$ seconds.

The cache mechanics explain the determinism defect. The discovery cache
is keyed by the exact window bytes, the column set, the method and the
hyperparameters, with atomic writes. A key miss halts the run rather
than silently refitting a subtly different graph. The data-determinism
defect of Section~\ref{sec:cache} was caused by EEM's 2003 inception
falling within the padding window of the cache-coverage check. This
caused a silent re-download whose auto-adjustment jittered values by
${\approx}3\times10^{-7}$ from run to run. The non-convex DYNOTEARS
optimiser amplified this into graph changes of ${\approx}0.14$ in
$\lVert W\rVert$. VARLiNGAM's ICA-on-residuals fits were mostly
unaffected by the same jitter, which is a small robustness result in its
own right.

Regarding the environment and data access, I worked within the
repository's virtual environment on Python 3.13. \texttt{causalnex} and
\texttt{lingam} are vendored (source-tree imports via
\texttt{\_vendored.py}) rather than pip-installed, so the repository
itself pins their exact versions. All commands are run from the
repository root, from which \texttt{pipeline} imports as a package. The
raw market data requires a WRDS/CRSP licence, but the fitted graphs and
derived series are committed to the content-keyed cache, meaning that
every result in this report can be regenerated offline without it.

The report is reproduced in four steps, each idempotent against the
cache. (1) Run the unit-test suite (60+ tests, including the
orientation-blindness and orientation-sensitivity properties of
Section~\ref{sec:ablation-design}). (2) Run the backtest grid, which
verifies that each graph fit is a cache hit (a miss halts the run rather
than silently refitting). (3) Rebuild the statistics macros with
\texttt{scripts/robust\_stats.py -{}-phase-ii}. (4) Rebuild the figures
with \texttt{scripts/plot\_phase\_ii\_figures.py} and compile the
report.

On provenance, every statistic cited in the text is either a generated
macro (\path{_generated/robust_stats.tex}) or traceable to a committed
CSV (\path{results/phase_ii_matrix.csv}, \path{phase_ii_contrasts.csv},
\path{robust_stats_phase_ii.csv}, \path{regime_analysis/},
\path{oos_slice.csv}/\path{oos_contrasts.csv}). Every figure is
regenerated by the plotting script above. No result in the 2007--2024
panel relies on a live network fetch.

The out-of-sample slice of 2025--26 (Section~\ref{sec:oos}) is
regenerated by \path{scripts/run_oos_slice.py} (per allocator and
window) followed by \path{scripts/collate_oos.py}. Its protocol,
price-source rule and outcome interpretations were pre-specified in the
repository file \path{PREDICTIONS_OOS.md}. The slice has its own separate price and
driver caches (\path{cache/prices_oos}, \path{cache/drivers_oos}), so
the 2007--2024 CRSP caches are never overwritten. Its asset prices are
sourced from Yahoo Finance since CRSP daily data ends on 2024-12-31
(verified against WRDS on 2026-08-15). Its DYNOTEARS fits join the
shared content-keyed discovery cache under their own keys.
